# ADR-0045: относительные перемещения и целое положение карточки

Дата: 2026-11-07. Статус: реализовано в P04.05; результаты —
[EV-069](../../agent/verification/EV-069-move-order.md).

## Решение

`card.move` задаёт пространство, карточку, целевую колонку, `before` и исходную
версию карточки. `column.move` задаёт пространство, колонку, `before` и исходную
версию колонки. `before=null` означает конец активного списка, иначе — вставку
перед указанным активным объектом того же контейнера. Себя как соседа указывать
нельзя. ID объектов сохраняются; перенос между пространствами запрещён.
Положение соседа разрешается в текущем состоянии под writer lock. Версия
проверяется у перемещаемого объекта: правка другой карточки не отменяет действие.
Если сосед уже вне целевого списка, команда отклоняется без изменения данных.

Ядро сохраняет расширяемый лексикографический ранг из компонентов `digit: u32`
и `id`. При равном промежутке ID обеспечивает устойчивый порядок разных
объектов. Вставка не перенумеровывает соседей и не делает их версии устаревшими.
После расхождения верхней границы распределитель сначала использует свободные
цифры суффикса; обычные последовательные вставки не удлиняют путь на каждом шаге.
В отличие от дробных чисел, путь можно удлинить без потери точности. Это перенос
проверенного принципа P02.03.2, а не зависимость от кода прототипа.
Разные варианты положения одного объекта остаются конфликтом, не сортируются
вместо ручного решения. API возвращает список уже в общем порядке.

У карточки колонка и ранг сохраняются одним скалярным JSON-присваиванием
`placement`. Снимок содержит целые `placements` и производные `columns`/`positions`;
при независимых перемещениях сохраняются пары, а не их декартово произведение.
Это одно положение одного корневого объекта, не копирование карточки.
Обычные изменения блокируются при собственном конфликте. Спорное положение
соседа исключается из обычного списка; конфликт только текста/названия соседа
не мешает использовать его однозначное положение. Карточки колонки со спорным
названием или порядком продолжают работать при отсутствии своих конфликтов.

Семантическая схема 5 добавлена в защищённый реестр с прежним DDL и архивным
адаптером. Переход требует существующие проверенные копии и общий startup gate;
графы, actor/peer и receipts не переписываются. Старые writers не допускают v5.
При отсутствии `placement` прежние `column`/`position` остаются авторитетными.
После первой реальной move авторитетно только `placement`; старые поля —
неизменяемая историческая основа. Поэтому актуальность не оживает после ABA,
а техническая история состава обеих колонок сохраняется. Исходные числовые
позиции читаются без изменения; новый путь сериализуется строкой в графе,
а в API — массивом компонентов. Legacy u64 сравнивается как два u32-компонента
с ID. Добавление после пути также использует общий распределитель ранга.

Старые receipts с числовыми `positions` и без `placements` декодируются и
возвращают исходный результат. Это подтверждение прежней команды, не текущий view.
`placements` отсутствует также в снимках карточки, которую ещё не перемещали;
для неё `columns`/`positions` читаются как прежде. Клиент не вычисляет ранг
и не передаёт его в команду.

## Сохранность и границы

ReadWrite, актуальность, активные родители, атомарные граф/receipt и проверка
доступа перед replay общие для HTTP/CLI/IPC. Перемещение обратно — новая команда
с актуальной версией. Уже достигнутое место — noop без смены версии; устаревшая
версия всё равно отклоняется. Текст, история, теги, выполнение и корзина
не меняются. Корзина и восстановление сохраняют новое положение.

Схема локальной базы не определяет совместимость обмена. P06 должен согласовать
поддержанные кодировки до принятия удалённых изменений; обмен со старым writer,
не знающим `placement`, не объявляется совместимым. UI/жесты — P05.05,
ручное разрешение конфликтов и продуктовый обмен — P06. Пути могут расти при
многократной вставке в один промежуток; нет скрытой перенумерации или заявления
о проверке полного масштаба. Оптимизация потребует отдельных измерений.

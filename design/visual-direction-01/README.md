# Графит, Шов и Минерал

По выбору разработчика сохранены три дизайна:

- [Графит](02-graphite/index.html) — исходный макет.
- [Шов](graphite-lab/sol-01.html) — продолжение GPT-6.1 Sol Extra High.
- [Минерал](graphite-lab/astra-02.html) — продолжение GPT-6 Astra High.

Эти три прототипа выбраны как визуальные примеры для дальнейшей реализации
интерфейса ZeDone. Они задают направление оформления; продуктовые требования
и приёмка Windows/Android остаются в документации проекта.

[Главный HTML](index.html) содержит все три страницы внутри себя. Его можно
скопировать одним файлом и открыть без сервера, сборки и сети.
Остальные восемь продолжений DESIGN-03 удалены по поручению разработчика.

Выберите дизайн, размер ПК или телефона (360/390/412 px), при необходимости
включите сравнение с оригиналом. Макеты масштабируются по доступной ширине;
«Открыть отдельно» открывает выбранный макет в натуральном размере.
«Сбросить демо» возвращает исходные данные в обеих рамках.

Все три макета сохранены без изменений. При отдельном открытии исходного
«Графита» сохраните рядом `shared/demo-data.js`; в каталоге его данные встроены.
«Шов» и «Минерал» автономны и содержат точную копию этого демо-сценария.
Дизайн-планы и палитры находятся в комментариях их HTML.

Поиск, просмотр, создание, редактирование с отменой, перемещение выбором колонки,
удаление и восстановление работают только в памяти страницы. У каждой рамки
собственная сессия; переключение дизайна и сброс возвращают исходный сценарий.
Продуктовый API, SQLite и синхронизация не подключены. Мобильная компоновка
не подтверждает нативную работу Android Device/APK/WebView.

Результаты исходного раунда — EV-061, текущий состав и проверка — LOG-291.

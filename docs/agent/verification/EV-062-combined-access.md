По [ADR-0040](../../architecture/decisions/0040-space-creation-access.md)
отдельное право создания не вводится. В этом срезе готовится модель,
которая позволит администратору сохранить управление доступами и получить
RW только нового пространства. Само создание и атомарная выдача создателю
будут проверены вместе с обратимым жизненным циклом в P04.01.2.

Ориентир 300 ручных строк превышен из-за неделимой проверки одной границы
авторизации: её постоянная модель, защищённая смена семантики схемы,
исторический отказ, обратимость/атомарность и одинаковый строгий результат
всех адаптеров должны быть рассмотрены вместе. Сама прикладная реализация
вынесена в зависимый шаг; попутного рефакторинга и новых зависимостей нет.

## Матрица

| Область | Проверка |
| --- | --- |
| Guard | ActiveGrant для всех действующих областей; отсутствие/ошибка источника, пустая/неверная область, срок и отзыв дают отказ; запрос существующего пространства требует отдельного точного права |
| Совмещение | Read/ReadWrite отдельно от администрирования; доступ к a не разрешает b; сохранение после restart |
| Обратимость | Снятие данных с сохранением последнего admin; отказ понизить последнего admin; отзыв/свежая выдача тому же субъекту, старые ключи не оживают |
| Атомарность | Пустой набор/неизвестный ID/ошибка после выдачи/перехваченная ошибка mutator откатывают данные, права, ключи и receipt |
| Миграция | v1/v2/v3→v4 с проверенной копией; отказ без копии; неизменённые прежние права/версии/actor/данные/peers/receipt; историческая v3 не принимает совмещение, испорченная v3 сохраняется и отклоняется |
| Адаптеры | HTTP/IPC и настоящий процесс CLI возвращают один совмещённый snapshot и исходный replay; отзыв запрещает чтение уже существующего receipt |
| Производные | Rust/OpenAPI/TS/standalone validator; клиент принимает новый строгий вариант, отвергает подмены режима и лишние полномочия |

## Пять правил и границы

- Обратимость: снятие точного доступа с сохранением администрирования,
  отзыв/свежая выдача и защита последнего admin проверены; старая область
  не оживает через прежний ключ или replay. Смена версии схемы — внутренний
  защищённый переход, понижение версии не является пользовательским действием.
- Человек и агент: один core/Storage/Service; HTTP, IPC и настоящий CLI
  показывают одну совмещённую область и применяют одинаковый отзыв до receipt.
  Само создание пространства через эти входы ещё относится к P04.01.2.
- Документация: спецификация/ADR-0040, инструкции пользователя/агента/разработчика,
  архитектура, очередь, журнал и данный EV обновлены. DEC-010 resolved решением
  разработчика, реализация не подменяет его трактовкой отдельного разрешения.
- Паритет: одинаковая нативная матрица Windows/Android x86_64 и сборки обеих
  Android ABI с Tauri bridge passed. Пользовательские экраны, APK/WebView
  и выполнение на физическом arm64 этим срезом не принимаются.
- Источник истины: прежняя SQLite хранит права вместе с данными/receipt;
  клиентские типы и validator выведены из Rust. Отдельной таблицы/кэша
  полномочия создания, новых пользовательских полей или запасной базы нет.

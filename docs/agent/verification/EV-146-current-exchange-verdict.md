новый S07, storage Clippy, native Android, полный UI, отдельные Chrome/Opera
pairing, policy и парный APK fields. Все exit0. Сверены три порядка новых и
сохранённых решений, native S07, результаты парных fields и двух container
прогонов: passed/restored/cleanup. Отдельные Device-наблюдения подтверждают
явный выбор, отмену и сохранение после restart. Это проверка сохранённых
результатов, а не новые runtime-прогоны.

timeout/manual, реальные 8 381 688 байт false→true/state4/error0, точный свежий

ModuleInstallClient после штатного check-in; самостоятельная автоматическая
доставка исходным background-запросом не доказана и не требуется формулировкой
A51 о допустимой первой загрузке и повторе после готовности.

Штатным PR API заново прочитаны [PR #119](https://github.com/Zeyafix/zedone/pull/119)

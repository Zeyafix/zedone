# Визуальная проработка: Графит, Шов и Минерал

По выбору разработчика (LOG-291) оставлены исходный «Графит», «Шов» и «Минерал».
Использовать эти три прототипа как визуальные примеры при дальнейшей реализации
интерфейса ZeDone. Выбор фиксирует ориентиры оформления, а не переносит демо-код
в продукт и не меняет продуктовые требования или статус приёмки.
Остальные восемь продолжений DESIGN-03 удалены, включая их встроенные копии
в каталоге и локальные визуальные артефакты.

[Главный HTML](../../design/visual-direction-01/index.html) содержит все три
сохранённых дизайна, переключение размеров ПК/телефона, сравнение с оригиналом,
отдельное открытие и сброс демо. Исходники встроены в JSON внутри HTML,
затем открываются через `iframe.srcdoc`; отдельное открытие использует Blob.
Внешних ресурсов и сервера нет, каталог можно переносить одним файлом.
Отдельные HTML продолжений — `graphite-lab/sol-01.html` и `graphite-lab/astra-02.html`.
Состав и управление описаны в [README](../../design/visual-direction-01/README.md).

Все три макета сохраняются побайтово. SHA-256 оригинала `02-graphite/index.html`:
`2a9e17459fb3058be416a02b7344a49fc017f531b21086b1325d7d87ac573f6d`.
Общий fixture `shared/demo-data.js` встроен в продолжения без изменения;
каталог встраивает его и в копию оригинала, сохраняя исходный файл.
При изменениях отдельных макетов следует синхронизировать встроенные
HTML каталога. Источник каждой встроенной страницы указан её полем `file`.

Внутри страницы одно состояние, используемое семантическими элементами управления
человека и агента. Рамки независимы; изменения только в памяти. Продуктовые
пространства, API/SQLite, нативные оболочки и продуктовая очередь не изменяются.
Адаптивная мобильная компоновка не равна проверке Android Device/APK/WebView.

EV-059/060/061 и прежние записи журнала сохраняются как история раундов.
В DESIGN-03 пять GPT-6.1 Sol Extra High и пять GPT-6 Astra High создали по одному
HTML; из них выбраны «Шов» (Sol) и «Минерал» (Astra). EV-061 описывает исходный
полный раунд, а LOG-291 — текущий состав и проверку сокращённого каталога.
Перенос дизайна в приложение требует отдельного поручения.

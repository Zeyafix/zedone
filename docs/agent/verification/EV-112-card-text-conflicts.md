не ослаблялись, raw logs всех попыток сохранены в ignored reports.

общим desktop/touch сценарием. Ручное сохранение выполнено после прокрутки кнопки
внутрь видимой области; результат, история и restart подтверждены отдельно.

## Пять правил

- Обратимость: выход без записи, новая обычная правка/восстановление версии;
  позднее изменение не отменяется повтором прежнего решения.
- Человек/агент: одна команда/права/expected и результат через UI/HTTP/IPC/CLI.
- Документация: user cards, agent cards/text-conflicts, developer product-core,
  ADR-0067, EV-112 и journal/queue входят в срез.
- Паритет: Windows/native Android/настоящий APK/Device и обе production ABI
  подтверждены в приведённом охвате; физический телефон не заявляется.
- Источник истины: прежние Automerge registers, SQLite/replay и история;
  UI не хранит независимое авторитетное состояние вариантов.

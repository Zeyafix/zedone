# Колонки

Колонка принадлежит пространству. Сейчас общий API позволяет создать пустую
колонку, прочитать/перечислить колонки, переименовать, отправить в корзину
и восстановить. Формы управления доступны в интерфейсе; изменение порядка пока через API.
[Карточки](cards.md) доступны через общий API; экран редактора — следующий шаг.

Названия сохраняются точно, включая пробелы, Unicode и пустую строку.
Одинаковые названия не объединяют разные колонки. Новая колонка добавляется
в конец; восстановление сохраняет исходное место. Корзина сохраняет данные
и идентичность колонки. Переименование можно отменить новой обратной правкой.

Если колонка изменилась после чтения, старая команда отклоняется целиком.
Нужно перечитать состояние и явно выполнить действие заново. Изменение
соседней колонки само по себе не отклоняет действие над выбранной.
Если ответ потерялся, повтор исходного запроса проверяет прежнее выполнение,
не дублирует колонку и не отменяет более позднее восстановление.

Доступ определяется правами пространства. В пространстве в корзине новые
изменения колонок запрещены. Удаление колонки с содержимым и пространства
с колонками добавляется отдельно; неподдерживаемое содержимое не удаляется.


Через общий API можно переставить колонку перед другой колонкой пространства
или в конец, затем вернуть обратно. Её карточки сохраняются вместе с ней;
их данные и порядок внутри колонки не меняются. Новое положение сохраняется
при перезапуске и корзине/восстановлении. Перетаскивание в интерфейсе — P05.05.

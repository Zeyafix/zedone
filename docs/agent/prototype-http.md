# Ограниченный HTTP-прототип для агента

Локальный владелец запускает временную сессию через форму APK/IPC
`http_session` или stdin режима `serve-echo --limited` на ПК.
Модели `HttpSessionRequest/Status` — в Rust/OpenAPI components. Управление
не опубликовано на удалённом HTTP. Получите endpoint и ключ из разрешённой
сессии; не выводите ключ в логи/документацию.

Используйте POST маршрутов из `prototypes/openapi.json` с заголовками
`Content-Type: application/json` и `Authorization: Bearer …`.
По умолчанию разрешены только read/snapshot A и stateless операции.
Изменения A требуют явного write при запуске. Любая операция B запрещена;
HTTP и IPC APK читают/меняют один Storage, UI не является источником данных.

401 означает неверный/отозванный ключ; 403 — запрет полномочий/области/Origin.
Нет соединения — нет доступного listener/пути сети. Ни одна из этих ошибок
не разрешает обход через SQLite, выдачу прав или автоматический запуск.
Потеря ответа/тайм-аут изменения не означает откат: перечитайте состояние
через разрешённый путь и подготовьте действие заново. Для перемещений
по-прежнему обязателен актуальный expected; снимок/восстановление и обратные
перемещения используют существующие операции общего ядра.

Home/сон/пересоздание/force-stop отзывают сессию; возврат не возобновляет её.
Для продолжения владелец явно запускает новую с новым ключом. Изменение,
допущенное до отзыва, может уже завершиться. Продуктовые права и обмен
не реализованы; реальный Tailscale IPv4 проверен в синтетическом P01.10,
но итоговые T04/A26, выбор транспорта и продуктовые права ещё не приняты.
Воспроизведение: [инструкция](../development/android-http-prototype.md),
доказательства: [EV-023](verification/EV-023-android-http.md).

BUG-002: после перезапуска VPN внутри Android listener может оставаться
в локальном status активным при отказе настоящих новых TCP-соединений.
Статус не доказывает сетевую доступность. Временное восстановление — явные
локальные stop/start владельцем и новый ключ; удалённый агент не получает
права перезапускать сервер. Автоматически повторять неизвестное изменение
нельзя. Ошибка не устраняется выдачей более широких прав Tailscale.

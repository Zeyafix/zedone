# Quick Start: ZeDone на Windows 11

ZeDone пока находится в разработке. Готового пользовательского выпуска,
установщика и начальной настройки доступа ещё нет. Сейчас можно попробовать
интерфейс на отдельной тестовой установке: создать пространства и колонки,
переименовать их, отправить пустые объекты в корзину и восстановить.
Редактор карточек и синхронизация между устройствами пока недоступны.

## Что понадобится

- Windows 11 x64 и браузер Chrome или Opera.
- Рабочая копия ZeDone с подготовленными файлами
  `target/debug/serve-shell.exe` и `target/debug/examples/shell-fixture.exe`.

Если этих файлов нет, сначала потребуется
[сборка для пробного запуска](../development/ui-shell.md#сборка-для-пробного-запуска-windows).
Это временный путь из исходников с инструментами разработки. Запуск без них
станет доступен после подготовки пользовательского выпуска.

## Первый запуск

1. Откройте папку ZeDone в Проводнике и выберите «Открыть в Терминале».
   Используйте вкладку PowerShell. Все команды ниже выполняются из корня
   рабочей копии — папки, в которой находится `README.md`.

2. Один раз подготовьте отдельную тестовую установку:

   ```powershell
   .\target\debug\examples\shell-fixture.exe --prepare "$env:LOCALAPPDATA\ZeDone\Demo"
   ```

   Дождитесь завершения без ошибки. Эта служебная программа создаёт тестовую
   базу и локальный доступ; она предназначена только для знакомства
   на тестовых данных. Каталог должен быть новым или пустым.
   Если он уже содержит прежнюю тестовую установку, пропустите этот шаг.
   Не применяйте подготовку к рабочим данным и не очищайте существующую папку
   ради повторного выполнения команды.

3. Запустите ZeDone:

   ```powershell
   .\target\debug\serve-shell.exe --data-directory "$env:LOCALAPPDATA\ZeDone\Demo"
   ```

4. Терминал выведет адрес вида `http://127.0.0.1:54321`.
   Откройте именно выведенный адрес в браузере. Номер порта может отличаться
   при каждом запуске. Терминал оставьте открытым.

## Первые действия

1. Дождитесь состояния «Доступ подтверждён».
2. Нажмите «Создать пространство», введите, например, `Daily` и подтвердите.
3. Откройте пространство по названию и нажмите «Создать колонку».
4. Попробуйте «Переименовать». Чтобы отменить правку, переименуйте объект обратно.
5. Отправьте пустую колонку «В корзину», откройте «Корзина» и нажмите
   «Восстановить». Кнопка «Активные» возвращает обычный список.

Пока в интерфейсе можно работать только со структурой: добавить карточку
с делом ещё нельзя. Подробности навигации, тем и незавершённых действий —
в [руководстве по интерфейсу](interface-shell.md).

## Остановка и повторный запуск

Перед остановкой проверьте результат незавершённых действий, если они появились.
Для остановки нажмите `Ctrl+C` в терминале. Закрытие вкладки браузера само
по себе сервер не останавливает.

При следующем запуске откройте PowerShell в той же рабочей копии и выполните
только команду запуска из шага 3. Подготовку из шага 2 повторять не нужно.
Откройте новый адрес из терминала: прежняя вкладка может указывать на старый порт.
Пространства и колонки сохраняются в той же локальной базе.

Тестовые данные находятся в `%LOCALAPPDATA%\ZeDone\Demo`. Не передавайте
содержимое этой папки другим людям: вместе с базой там хранится локальный доступ.
Чтобы полностью удалить тестовую установку, сначала остановите сервер,
затем удалите только эту папку через Проводник. Это удалит её данные без восстановления.

## Если не получилось

- **PowerShell не находит `serve-shell.exe` или `shell-fixture.exe`.**
  Проверьте, что терминал открыт в корне рабочей копии и сборка завершилась успешно.
- **Подготовка сообщает `Fixture refuses nonempty directory`.**
  Папка уже занята. Для прежней тестовой установки выполните только запуск;
  для новой выберите другую пустую папку и укажите её в обеих командах.
- **В браузере «Доступ не настроен» или «Нет доступа».**
  Проверьте, что подготовка завершилась успешно и запуск использует ту же папку.
  Одна команда запуска не выдаёт доступ новой базе. Если подготовленная установка
  по-прежнему недоступна, передайте разработчику текст ошибки без содержимого
  `local-session.json`.
- **Браузер не соединяется с ZeDone.**
  Проверьте, что процесс в терминале работает, и откройте его текущий адрес.
- **Появилось «Не удалось связаться с ядром» или `ZeDone shell could not start`.**
  Передайте разработчику сообщение и обстоятельства запуска. Сохраните каталог
  данных; повторная подготовка поверх него не является способом исправления.

На Android пользовательский путь установки и настройки ещё готовится.
Эта инструкция относится к пробному запуску Windows; она не подтверждает
готовность пользовательского выпуска ни на одной из платформ.

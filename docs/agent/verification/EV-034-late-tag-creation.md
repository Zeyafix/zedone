Один наблюдаемый результат: принятый в LOG-215/ADR-0012 поздний мост
разрешается общей операцией выбора имён. Связная группа включает три исходных
тега, даже если текущее имя первого уже отличается. Причинность созданий
навсегда сохраняет их раздельность; завершённый выбор снимает временные
блокировки. Данные берутся из существующего документа Automerge в SQLite,
новый формат хранения не нужен.

Проверки охватывают конкурирующие решения, старую/повторную/переставленную
доставку, сохранение после перезапуска, допустимые правки карточки и обратные
действия. Это одна неделимая операция с атомарностью и двумя платформами;
ориентир 300 строк превышен из-за её общей матрицы сохранности.
Удаление тегов, продуктовые UI/API/права, полная Unicode-политика,
физический arm64 и масштаб/память остаются за пределами этого шага.

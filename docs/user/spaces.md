# Пространства

Операции колонок описаны в [инструкции колонок](columns.md).

Общий API позволяет создать пространство, получить список доступных пространств,
прочитать и переименовать пространство, отправить пустое пространство в корзину
и восстановить его. Пользовательские экраны этих действий относятся к P05.

Создавать пространство может любой участник с действующим доступом, включая
администратора и участника с доступом только для чтения. Он получает чтение
и изменение нового пространства. Доступ к остальным остаётся прежним;
срок и отзыв продолжают действовать. Администрирование само по себе
не открывает содержимое других пространств.

Пространства упорядочиваются по имени; равные имена не объединяют их.
При конфликте доступны все сохранённые варианты имени, спорные названия
показаны в начале списка. Обычное переименование не перезаписывает конфликт;
разрешение конфликтов относится к продуктовой синхронизации.

Удаление пустого пространства отправляет его в корзину. Данные и история
сохраняются, восстановление возвращает прежнюю идентичность. Переименование
обратимо новой правкой. Удаление контейнера с содержимым в этот срез не входит.

Если данные изменились после чтения, старая команда отклоняется целиком:
нужно перечитать состояние и явно подготовить действие заново. При потере
ответа действие уже могло сохраниться. Повтор исходного запроса уточняет его
результат, не создаёт второе пространство или группу удаления и не отменяет
позднее восстановление. Подробнее — [срок доступа и повтор действия](access-time-and-retries.md).

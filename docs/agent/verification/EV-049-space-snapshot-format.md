## Реализовано

`Storage::snapshot` читает один scoped журнал в SQLite read-транзакции,
с предварительной оценкой размера и сверкой stored hashes. Сохраняются все raw
changes, включая ожидающие зависимости. Двоичный `SpaceSnapshot` v1 содержит
строгие метаданные исходного ID/даты, записи по hash и общий SHA-256.
Версия, структура, длины, записи, внутренние checksum и совместимость графа
проверяются до возврата объекта; исходный slice не изменяется.

Права, receipts, локальный actor для продолжения записи, peer progress и
настройки не переносятся. Исторические actor IDs внутри графа сохраняются.
Авторитетные данные остаются в одной SQLite; снимок — неизменяемая копия,
не второй редактируемый набор полей. `SnapshotLimits` ограничивает вход,
но не обещает предел памяти/времени. Подробности —
[ADR-0032](../../architecture/decisions/0032-space-snapshot-format.md).

Эталон v1 — исходная синтетическая проверка будущей совместимости, не ранее
официально выпущенный формат. Весь журнал проверен на синтетической модели;
продуктовая модель и проверка её схемы остаются P04/P07.02/P07.03.

## Пять правил и ограничения

- Обратимость: кодирование/декодирование сохраняют полный журнал; обратная правка
  и restart не изменяют уже полученную копию. Декодер не пишет в базу/исходник.
- Человек/агент: один внутренний формат и storage; публичных входов нет.
  Перед их включением права и захват должны выполняться в одной транзакции.
- Документация: ADR/архитектура/разработка/агентские границы/EV/очередь/журнал.
  Пользовательское поведение не добавлено.
- Паритет: одинаковые 68 тестов Windows/нативного Android x86_64 и обе ABI
  release/unsafe прошли. Физический arm64, APK и локальный Linux не проверялись.
- Источник истины: один журнал SQLite/Automerge, без копии прав/служебных данных.

Нет импорта/новых ID, восстановления/паузы, файлового хранилища/выбора папки,
каталога, ежедневных/страховочных политик, полной копии базы, миграций,
публичного API/UI, проверки физического arm64 или бюджета всего приложения.
Формат не разрешает обход ADR-0030 при будущем откате базы.
T10/A09/A25/M07 не объявляются полностью пройденными; DEC-006 остаётся open.

Собственный read-only AVD остановлен, remote sandbox очищен; инструменты и

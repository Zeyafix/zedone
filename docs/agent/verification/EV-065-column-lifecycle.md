Ориентир 300 ручных строк превышается одним неделимым жизненным циклом:
создание сразу имеет обратимые корзину/восстановление и одинаковый строгий
контракт, права и повторы через все входы. Независимый UI остаётся P05.02.
Удаление колонок с карточками/всего пространства с содержимым — P04.03/P04.09;
неизвестное содержимое блокирует корзину/восстановление. Это не полная A55/A56.

План проверки: неизменные исходные намерения и отказы доступа через все входы;
причинные версии только целевой колонки (включая удалённых потомков), исключение
другой колонки/корневой history; parent state gate; конфликты/неизвестные данные;
SQL rollback, потеря ответа, перезапуск и конкуренция.

## Реализовано

Шесть конкретных команд и их Rust-derived OpenAPI/TypeScript/standalone
validators; общий Service HTTP/IPC/реальный CLI. Модель/пределы —
[ADR-0043](../../architecture/decisions/0043-column-lifecycle.md).
Данные и receipts находятся в прежней SQLite/Automerge; SQL-схема/lockfiles
не менялись. Пространства без колонок сохраняют прежние версии.

| Проверка | Доказательство |
| --- | --- |
| Полный жизненный цикл | Unicode и пустое имя, обратное переименование, корзина/восстановление, прежние ID/позиции, новое удаление получает новую группу |
| Повторы | Старое удаление не отменяет восстановление, старое восстановление не отменяет новое удаление; создание после restart не дублируется; изменение параметров выполненного ID даёт mismatch |
| Актуальность | Изменение имени с возвратом и создание/удаление вложенных данных не оживляют старую версию; неизвестное содержимое колонки/корня пространства блокирует trash/restore целиком; удаление неизвестного корневого поля не оживляет прежнюю версию |
| Изоляция | Соседняя колонка, корневая history, чтение/receipt и peer progress не меняют версию цели; версия пространства учитывает изменения колонки |
| Конфликты | Разные name/position/lifecycle сохранены при чтении/списке; обычные rename/trash не выбирают вариант |
| Авторизация | Read не разрешает изменения; отзыв запрещает повтор чтения и создания, истёкший доступ не создаёт объект; состояние родителя блокирует новые изменения |
| Атомарность | Создание откатывается после работы/flush и перед commit; реальный SQL abort receipt откатывает rename; после commit возвращается OutcomeUnknown с последующим replay |
| Конкуренция | Два workers: один эффект создания и один replay; конкурентные rename/trash по одной версии не могут оба сохраниться |
| Транспорт | HTTP, IPC и реальный CLI используют один результат/receipt, отказы, restart; недопустимые ID/подмена прав/дубли полей отклоняются |
| Клиент | Сохранены родитель/ID/исходная версия после restart, ответ другой операции не подтверждает намерение; валидатор из Rust отклоняет неверный вложенный результат |

## Локальные проверки

Windows `bun scripts/check-product.mjs` — passed: 174 Rust-теста
(12 core access, 7 contract, 142 storage, 13 adapters), 15 клиентских тестов/
109 assertions, fmt/Clippy с -D warnings, release всех targets,
7 независимых отказов unsafe и побайтовая сверка Rust/OpenAPI/TS/validator.
Восемь новых Rust-тестов и один клиентский относительно принятого runtime
P05.01; прежняя матрица сохранена. Проверка типов UI через vue-tsc и Vite
production build также passed; UI-сценарии не менялись.

Android `bun scripts/check-product.mjs --android` — passed: те же 174
нативных Rust-теста, включая настоящий CLI и прежнюю crash/reopen матрицу,
те же 15 клиентских/109 assertions, release x86_64/aarch64 и 14 независимых
отказов unsafe. Выведенный Android-контракт побайтово совпал с host.
В сумме Windows/Android — 21 независимый unsafe guard.

Эмулятор открыт через Device. Нативные процессы запущены штатным CLI runner,
без UI-действий через adb; sandbox удалён в finally. Сессия Device закрыта,
предварительно работавший эмулятор оставлен включённым. Разработчик поручил
публикацию, merge после успеха и удаление ветки (LOG-319); CI/интеграция
ещё ожидаются. Логи машины остаются только в игнорируемых
`docs/reports/p04-02-windows.log`, `p04-02-android.log`, `p04-02-contract.log`.

Это API-срез пустой колонки. Карточки/состав/группы контейнеров, UI/APK,
продуктовый обмен, физический arm64 и полный бюджет приложения не приняты.

состояние done не объявляется до требуемых CI/интеграции.

## Пять правил

- Обратимость: создание сразу имеет корзину/восстановление; обратное
  переименование, сохранность идентичности/позиции/групп и поздних действий проверены.
- Человек и агент: одни Service/handlers/guard/replay через HTTP/IPC/CLI;
  формы UI колонок остаются P05.02, отдельного обхода агента нет.
- Документация: user/agent/development/architecture, ADR-0043, очередь,
  критерии журнала и передача обновлены.
- Паритет: одинаковые 174 нативных Rust-теста Windows/Android x86_64,
  release обеих Android ABI; APK/UI/физический arm64 вне охвата.
- Источник истины: прежние SQLite/Automerge и транзакционные receipts;
  Rust — источник API/типов/валидаторов, pending хранит только доставку.

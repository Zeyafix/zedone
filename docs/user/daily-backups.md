# Ежедневные резервные копии

При работающем приложении изменённое пространство автоматически сохраняется
при первой подходящей возможности, не чаще одного успешного снимка за
календарную дату устройства. Новое пространство тоже получает первую копию.
Без изменений копия не создаётся; пропущенные дни не восполняются.
Остаются последние 7 успешных копий каждого пространства. История, корзина,
конфликты и последние сохранённые правки входят в снимок.

Внутри пространства откройте «Ежедневные резервные копии». Там видны
состояние, дата последнего успеха и копии этой установки. «Обновить состояние
копий» перечитывает результат; открытая секция обновляется автоматически.

При ошибке папки работа с пространствами продолжается. Следующая автоматическая
попытка — через 5 минут от окончания неудачной. «Повторить сейчас» позволяет
не ждать; новая ошибка снова начинает пятиминутную паузу. Прежние копии
сохраняются, другая папка автоматически не выбирается. После успешного
повтора действует обычный дневной лимит. При неверных часах/поясе проверьте
настройки устройства; возврат к прежней дате не разрешает лишнюю копию.

«Сохранить копию в файл» выгружает полный переносимый снимок. На Windows
проверьте загрузку браузера; Android использует системный выбор файла.
Отмена не удаляет копию приложения. «Выбрать для восстановления» лишь
подставляет снимок в отдельную форму восстановления ниже. Пока вы не
подтвердили восстановление, пространство не меняется. После подтверждения
действуют [страховочный снимок и пауза обмена](space-recovery.md).

«Удалить эту копию» требует отдельного подтверждения и не меняет рабочее
пространство. При отсутствии других файлов этот снимок вернуть не получится;
при необходимости сначала сохраните его отдельно. Удаление не освобождает
дневной лимит. Если файл пока нельзя удалить, приложение сообщает об ожидающей
очистке и продолжит её позже; остальные копии сохраняются.

Если ответ изменяющего действия потерялся, используйте «Проверить результат»
в списке незавершённых действий. Не создавайте новое действие ради повтора
доставки. Папка пока стандартная, внутри локальных данных приложения;
выбор другой папки и полный каталог после переустановки — следующий шаг P07.05.

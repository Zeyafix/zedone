# Актуальность и повтор команды: текущая граница

Общий механизм реализован в ядре P03.04, но пользовательского HTTP/CLI/IPC
ещё нет. Напрямую вызывать низкоуровневый storage или менять SQLite агенту нельзя.
Реальные команды и их инструкции появятся вместе с общим API P03.05/P04.

Для будущих клиентов действуют правила ADR-0007/0008/0014:

- При неизвестном исходе сохранять исходные ID, операцию, цели, параметры и
  условия актуальности. Повтор доставки продолжает прежнее намерение.
- Результат повтора подтверждает прежнее выполнение. Он не заменяет актуальную
  карточку или контейнер и не отменяет более поздние правки.
- `stale_state` требует перечитывания и нового явного действия с новым ID.
  Автоматически подставлять новую версию в старое намерение нельзя.
- `command_mismatch` означает изменение запроса уже выполненного ID.
  Исправление не сводится к автоматической генерации другого ID.
- Права нужны при каждом обращении, включая получение прежнего результата.
  Недоступность и `outcome_unknown` не означают отсутствие данных или отказ записи.

Число автоматических попыток и интервалы ещё не определены; клиентский цикл
не реализован. Технический договор и ограничения —
[ADR-0030](../architecture/decisions/0030-command-replay-and-freshness.md),
проверенный охват — [EV-047](verification/EV-047-command-replay.md).

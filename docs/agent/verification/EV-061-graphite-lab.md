# EV-061 — DESIGN-03: десять продолжений Графита

Историческая проверка полного раунда. По следующему поручению разработчика
оставлены только «Графит», «Шов» и «Минерал»; восемь других продолжений
и их визуальные артефакты удалены (LOG-291). Ниже зафиксированы результаты
исходного раунда, а не текущий состав каталога.

Дата: 2026-11-06. Основание: прямое поручение разработчика, LOG-289.

## Состав и происхождение

Пять независимых GPT-6.1 Sol Extra High (`xhigh`) создали по одному HTML:
«Шов», «Картотека», «Киноварь», «Рельеф», «Орбита». Пять GPT-6 Astra High
создали «Партитуру», «Минерал», «Линзу», «Поля», «Монтаж». Все десять задач
запущены через T3 delegate_task с явно указанными моделью и reasoningEffort;
завершения получены. Каждый субагент изменил только свой HTML в `graphite-lab/`.
Планы, палитры и ограничения встроены комментариями в HTML.

[Каталог](../../../design/visual-direction-01/index.html) объединяет оригинал
и десять новых страниц. Доступны выбор варианта, размеры 1280/360/390/412 px,
сравнение с оригиналом, сброс обеих рамок и отдельное открытие.
Все страницы встроены в JSON; каталог автономен. Встроенная копия оригинала
содержит inline fixture, исходный файл оригинала не меняется.

SHA-256 исходного HTML до и после:
`2a9e17459fb3058be416a02b7344a49fc017f531b21086b1325d7d87ac573f6d`.
Десять встроенных HTML точно равны отдельным файлам, все содержат побайтовую
копию `shared/demo-data.js`. У каждой страницы собственное единое состояние.

## Реальные проверки родителя

- Chromium/Playwright через file://, без сервера: 44 компоновки (11 страниц ×
  1280/360/390/412 px). Нет ошибок JS, HTTP(S)-запросов, повторных ID и
  горизонтального переполнения документа. Снимки всех новых вариантов
  на 1280 и 390 px просмотрены: фон второстепенный, текст и карточки различимы.
- 22 сценарных прогона (11 страниц × ПК/390 px): поиск по всем колонкам,
  сброс поиска, открытие, отмена редактирования, сохранение, буквальный HTML,
  создание, удаление, восстановление, обратное редактирование и возврат fixture
  после перезагрузки. Все passed. Для «Линзы»/«Орбиты» проверка после
  перезагрузки выбирает «Разобрать»: стартовая колонка у них «В работе».
- Каталог на 1500 и 390 px: все 11 переключений, корректный srcdoc,
  сравнение, четыре ширины, сброс реальных поисковых запросов в обеих рамках,
  отсутствие внешнего переполнения/ошибок JS/HTTP(S). Прямая ссылка по hash
  и копия каталога в отдельной папке также passed.
- Синтаксис JS каталога/страниц, точность встроенных источников и fixture,
  отсутствие внешних script/link в новых страницах — passed. git diff --check
  чист; предупреждения Git об обычной нормализации LF/CRLF не являются ошибками.
- html_preview компактной встроенной версии каталога — без console messages.
  Для показа в сообщении удалены комментарии/отступы и изменено оформление
  внешней оболочки под тему T3; отдельные файлы и сохранённый каталог прежние.

Локальные JSON/снимки/manifest: `docs/reports/graphite-lab/`.
Скрипты воспроизведения локальной проверки: `temp/graphite-lab/`.
Эти игнорируемые артефакты не заменяют данную запись общих результатов.

## Пять правил и пределы

- Обратимость: проверены отмена редактирования, удаление/восстановление,
  обратное редактирование и сброс демо.
- Человек/агент: те же семантические кнопки/поля; Playwright управляет ими
  через доступные имена. Продуктовый API в макеты не подключён.
- Документация: README каталога, development-инструкция, журнал и эта EV
  обновлены. Продуктовые пользовательские/агентские договоры не меняются.
- ПК/Android: проверена адаптивная браузерная компоновка; Android Device,
  APK/WebView и нативные тесты не выполнялись. Нативный паритет не заявляется.
- Единый источник: точный общий fixture, внутри страницы одно состояние;
  сессии рамок независимы, данные только в памяти.

Продуктовые T/S-критерии и P03.05/BUG-004 не меняются. Коммита/PR/CI нет.
Следующий шаг — выбор или уточнение дизайна разработчиком; перенос в продукт
требует отдельного поручения.

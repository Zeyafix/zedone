# EV-128 — P06.07.1: объединение независимых созданий тегов

## Карточка

- База: main/83c4643; ветка `feat/p06-07-tag-convergence`.
- Зависимости: P06.04 done (EV-110), P05.06 done (EV-083).
- Цель: единая проекция независимо созданных одноимённых тегов с сохранением
  исходных ID, назначений и одного исходного написания на всех репликах.
- Требования: A20/A39/A49, ADR-0012/0046/0047; полные состояния критериев
  сохраняются. S05 и явные решения имён требуют следующих срезов.
- Объём: причинная проекция существующего Automerge-графа, aliases для чтения
  и обычных команд тегов, объединённые назначения, тесты общего API.
- Отказы: последовательное создание не объединяется; поздний мост сохраняет
  три ID и блокировку; переименование против создания остаётся коллизией.
- Обратимость: обычные переименование, снятие и повторное назначение через
  любой исходный ID; повтор receipt не возвращает позднее снятый тег.
- Проверки: Rust/API Windows и native Android; контракт, policy, клиент/UI
  и Device в доступном объёме. Результаты ниже заполняются после выполнения.
- Граница: P06.07 разделён на независимые .1 (создания/aliases), .2 (решение
  назначения/снятия S05), .3 (решение позднего моста A49), .4 (совместная приёмка);
  целый P06.07 не принимается
  по результатам только .1. Первоначальная реализация была локальной;
  публикация и условные merge/delete поручены в LOG-696. Оптимизация CI
  остаётся на паузе.
- Размер: причинная модель и её регрессионная матрица неделимы, могут превысить
  ориентир 300 строк; новые зависимости, схема и транспорт не добавляются.

Причинная проекция объединяет только независимые создания одного пространства
с равным Unicode-ключом начального имени. Списки показывают одну группу,

объекты и записи связей не удаляются. Представляющий ID — минимальный исходный;
исходное написание выбирается по Automerge operation ID. Переименование/снятие
поглощают наблюдавшиеся значения всех aliases в одной штатной транзакции.
Архитектурное основание — [ADR-0070](../../architecture/decisions/0070-tag-convergence.md).

## Ограничения и пять правил

- Обратимость назначения/снятия и переименования проверена через общий API;
  удаление тега сохраняет прежнее явное исключение без отдельного restore.
- Человек и агент используют прежние Service/HTTP/IPC/CLI и токены; новых
  обходных команд и клиентского алгоритма сравнения/объединения нет.
- Пользовательская/агентская документация и ADR обновлены.
- Паритет общего ядра проверен на Windows/native Android. Новый APK с Device UI,
  парная UI/API приёмка именно сходимости и физический arm64 в этот срез не входят.
  Эмулятор открыт/выключен инструментами Device; приложения/данные не заменялись.
- Единственный источник истины — существующий Automerge-граф, производного
  постоянного каталога aliases нет. Схема SQLite, формат JSON и lockfiles не меняются.

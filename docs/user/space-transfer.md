# Перенос пространства в файл

Откройте «Перенос пространства» в списке или внутри пространства.
Для экспорта откройте нужное пространство, нажмите «Подготовить экспорт»,
затем «Сохранить архив в файл». Архив включает колонки, карточки, теги,
корзину и историю, включая последние сохранённые правки. Исходник не меняется.
Файл содержит пользовательский текст и историю: храните его как личные данные.

Windows передаёт `space.zedspace` браузеру. Проверьте завершение в загрузках:
приложение не может подтвердить запись браузером на диск. Android открывает
системное «Сохранить как» и сообщает об окончании записи. Отмена сохранения
оставляет подготовленный архив в открытом интерфейсе; его можно сохранить
снова. После закрытия приложения подготовьте новый экспорт. Удалить сохранённый
файл можно в проводнике или системном приложении «Файлы».

Для импорта нажмите «Выбрать файл для импорта», выберите архив и подтвердите
«Импортировать выбранный файл». До подтверждения можно убрать файл или
отменить выбор. Каждое подтверждённое новое действие создаёт независимое
пространство с новыми идентификаторами. Подключения и чужой доступ не
переносятся. Пространство, которое находилось в корзине, сохраняет это
состояние; ищите его в корзине пространств. Копию можно изменить, отправить
в корзину и восстановить обычными действиями, не меняя исходник и файл.

Повреждённый, неподдержанный, пустой или слишком большой файл не создаёт
частичную копию. Текущая разовая передача ограничена архивом 1 MiB и
10000 изменений; это технический бюджет переноса, а не предел пространства.
При ошибке чтения выберите доступный файл снова. При ошибке записи архив
остаётся подготовленным: проверьте папку назначения и повторите сохранение.
После обрыва записи может остаться незавершённый файл — удалите его средствами ОС.

Если ответ ядра потерялся, используйте «Проверить результат» в списке
незавершённых действий, в том числе после перезапуска. Повтор продолжает тот
же экспорт или импорт и не создаёт вторую копию. Удаление записи из списка
не отменяет уже выполненный импорт. После подтверждения импорта перечитайте
список; восстановление исходного пространства из копии — отдельная операция.

# Колонки через общий API

P04.02 предоставляет column.create/read/list/rename/trash/restore через
общие Service/core/guard/replay на Windows и Android. Контракт —
`api/openapi.json`, типы/проверка ответа выведены из Rust. Прямые SQL-записи
или доверенные storage callbacks не заменяют API агента.

| Операция | Параметры | Доступ пространства |
| --- | --- | --- |
| `column.create` | space, column, name | ReadWrite, активный родитель, новый ID |
| `column.read` | space, column | Read/ReadWrite |
| `column.list` | space, include_trashed | Read/ReadWrite |
| `column.rename` | space, column, name, expected | ReadWrite, активные родитель и колонка |
| `column.trash` | space, column, expected | ReadWrite, активные родитель и пустая колонка |
| `column.restore` | space, column, expected | ReadWrite, активный родитель, пустая колонка в корзине |

Транспорт/ключ — как у [пространств](spaces.md): POST
`/v1/commands/<operation>`, CLI с --operation и JSON на stdin либо
zedone_command IPC с исходной строкой request и отдельным credential.
Субъект/права/часы не передаются в параметрах. Отдельных прав колонок нет.

Новый column — случайный ненулевой ID из 32 lowercase hex, например через
`newColumnId()`. Его и точное имя сохраняют в намерении до доставки:
`prepare(subject, "column.create", {space, column, name}, store)`.
ID команды независим. Равные/пустые имена разрешены и не объединяют объекты.

ColumnSnapshot содержит space/column, names, positions, state,
deletion_groups, empty и version. Список содержит columns. Добавление помещает
колонку после существующих позиций, восстановление сохраняет её место;
явное перемещение — P04.05. Конфликтующие варианты не скрываются и не
перезаписываются обычной командой. include_trashed=false исключает только
однозначную корзину. Для нового состояния read/list нужен новый ID команды.

expected берётся из version целевой колонки, а не пространства.
stale_state требует перечитать и подготовить новое явное действие;
автоматическая подстановка новой версии запрещена. conflict требует
разрешения доменного конфликта; операции разрешения относятся к P06.
При неизвестном исходе повторяют точный сохранённый запрос с тем же ID.
Receipt подтверждает прежнее выполнение, не заменяет актуальный view:
повтор удаления после восстановления не удаляет повторно, повтор создания
не создаёт другую колонку, позднейшие правки сохраняются.

Переименование обратно — новая команда, корзина обратима восстановлением.
Карточки доступны через [общий API](cards.md). Их наличие, включая корзину
и спорное положение, делает колонку непустой и меняет её причинную версию.
Удалённая принадлежность также учитывается; техническая история исключена.
Неизвестное содержимое колонки или корня
пространства блокирует корзину и восстановление, не удаляется частично.
Неизвестные корневые поля также меняют версию, включая изменение с возвратом.
Корзина пространства с колонками
остаётся P04.09, UI — P05.02. Архитектура — [ADR-0043](../architecture/decisions/0043-column-lifecycle.md).

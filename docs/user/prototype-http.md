# Тестовый доступ к открытому Android-прототипу

Форма «Тестовый HTTP-доступ» работает только с синтетическим пространством A.
Укажите IP этого устройства и порт, затем нажмите «Запустить тестовый доступ».
Для проверки на устройстве оставьте `127.0.0.1`; доступ с ПК через Tailscale
требует настройки обоих устройств и указания Tailscale IP Android.
Сетевой путь проверен на физическом Android в синтетическом прототипе.

Начальное право — только чтение. Если нужны изменения A, явно включите
«Разрешить изменения A» перед запуском. Пространство B недоступно всегда.
Адрес и временный ключ появятся только после успешного запуска.
Передайте их только агенту, которому разрешён тестовый доступ.

«Остановить и отозвать» выключает доступ. Для смены прав остановите его
и запустите заново; прежний ключ перестанет действовать. После сворачивания,
сна экрана, пересоздания или завершения APK требуется новый явный запуск.
«Обновить состояние» перечитывает фактическое состояние сервера.

Если адрес или порт недоступны, исправьте их и повторите запуск. При потере
ответа на изменение результат неизвестен: прочитайте данные через форму
SQLite или новую сессию, прежде чем решать, нужно ли повторять действие.
Удаление A обратимо через снимок/восстановление из формы SQLite.

Известная ошибка BUG-002: после выключения и включения Tailscale внутри
Android прежний доступ может отображаться включённым, хотя запросы с ПК
не проходят. Временно восстановить его можно через «Остановить и отозвать»
и новый явный запуск. Агенту потребуется новый ключ. Изменять настройки
сети для этого восстановления не нужно; исправление ошибки ещё предстоит.

Прототип не выдаёт права на реальные пространства и не синхронизирует устройства.
Настройка и границы проверки: [инструкция разработчика](../development/android-http-prototype.md).

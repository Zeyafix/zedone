Обоснование размера: один неделимый вопрос проверки — граница Rust-контракта
и невозможность unsafe на двух платформах. Ориентир 300 ручных строк превышается
из-за негативного компиляторного драйвера, CI и архитектурной документации;
генерируемые OpenAPI/lock учитываются отдельно. Новые продуктовые операции,
хранилище, права и адаптеры в этот срез не входят.

## Результат

Создан отдельный корневой workspace с `zedone-core`, независимый от прототипов.
Границы текущего пакета и будущих storage/адаптеров закреплены
[ADR-0027](../../architecture/decisions/0027-product-core-boundaries.md).
`Command` связывает запрос, имя и результат; `CommandResult` задаёт внутренний
результат обработчика. Строгая ошибка содержит только общий машиночитаемый код.
Неизвестный результат отделён от достоверного отказа. Реальных команд пока нет;
OpenAPI содержит только схемы, `paths` пуст. Это начало ядра, не готовый API.

При первой проверке строгий tagged unit enum Serde принимал лишние поля.
До финальных прогонов он заменён строгой структурой `CommandError` с `ErrorCode`;
регрессия проверяет отказ лишним полям и соответствие `additionalProperties: false`.

| Проверка | Результат |
| --- | --- |
| Windows `bun scripts/check-product.mjs` | fmt/Clippy всех targets/features, 3 теста, release всех targets/features, OpenAPI — passed |
| Android `bun scripts/check-product.mjs --android` | Те же 3 теста нативно на AOSP API33/x86_64; OpenAPI идентичен host; release всех targets/features для x86_64/arm64 — passed |

Проверки отказов — 11 сценариев, включая исходный успех и восстановление.
Отдельные локальные попытки с отсутствующим rustfmt-форматированием и запуском
PowerShell-скрипта через Windows PowerShell отклонены; формат исправлен,
эмулятор запущен штатным Start-Process, финальные прогоны завершены успешно.
Политики выполнения и настройки машины не менялись.

## Приёмка и ограничения

- Обратимость: контракт не меняет пользовательские данные; экспорт восстанавливается
  из Rust. Проверки работают в временной копии/собственном каталоге эмулятора,
  очищаемых в finally; собственный read-only AVD остановлен.
- Человек и агент используют один Rust-контракт и те же команды проверок.
  Реальные HTTP/CLI/IPC-входы и их паритет ещё не реализованы, относятся к P03.05.
- Архитектура, решение, инструкции разработки и план-журнал обновлены.
  Пользовательского поведения в этом срезе нет, новая инструкция UI не требуется.
- Windows и нативный Android x86_64 подтверждены для текущего контракта;
  arm64 только собран. APK/WebView/физическое устройство и полный UX не принимались.
- Rust — единственный источник типов/ошибок и OpenAPI. Продуктовое хранилище
  впереди; новый независимый набор пользовательских данных не появился.

T06/A17 — partial: текущая граница локально проверена, но хранение,
права, реальные адаптеры и платформенные исключения будущей оболочки впереди.
DEC-001 уточнён ADR-0027; реальная композиция проверяется P03.02–05.
DEC-002/DEC-003/DEC-009 не закрываются. Новых багов или блокеров нет.
Исходники прототипов не менялись, кроме последовательности CI callback;
полный прототипный APK/UI-прогон локально не повторялся.

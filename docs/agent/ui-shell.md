# Работа агента с оболочкой

Навигация доступна ссылками «Пространства»/«Настройки», на телефоне — в «Меню».
Тема выбирается radio-группой «Тема»: «Как на устройстве», «Светлая», «Тёмная».
Человек и UI-агент используют те же элементы. Это локальное предпочтение
представления, не прикладные данные.

Проверка доступа выполняет `space.list` через тот же Service и права, что
описаны в [spaces.md](spaces.md). Запущенный APK, session-файл и HTTP 200 сами
по себе не доказывают авторизацию. Секрет не выводить и не сохранять в
URL/pending/localStorage/отчёты. Проверка не выдаёт полномочий и не меняет
предметные данные.

Управление пространствами и колонками подключено к общему API (P05.02).
UI-агент использует «Создать пространство», ссылку с названием пространства,
«Создать колонку», «Переименовать», «В корзину», «Корзина»/«Активные» и
«Восстановить». Формы Reka Dialog имеют поле «Название», явное подтверждение
и отмену. На Android первое Back скрывает открытую клавиатуру, сохраняя ввод;
после скрытия клавиатуры Back закрывает форму до выхода из пространства.
Пустое название показывается как «Без названия»; при нескольких одинаковых
названиях выбирайте действие в строке/колонке нужного объекта.

Прикладной агент выполняет те же space/column команды через HTTP/CLI/IPC;
[пространства](spaces.md), [колонки](columns.md). Не заменять UI прямой записью
в SQLite. Неизвестное содержимое и конфликты сохраняют отказы общего ядра.
`shell_session`/`/host/session` —
внутренний порт доставки ранее выданной учётной записи, не обход guard.

P05.03.1 добавляет карточки внутри колонок. «Создать карточку» открывает поля
«Заголовок» и «Описание»; заголовок обязателен. Нажатие на заголовок читает
свежую карточку и открывает полный буквальный текст. «В корзину» требует
подтверждения; «Корзина карточек»/«Активные карточки» переключают список,
«Восстановить» возвращает прежний ID/место. Выбирайте кнопку в нужной колонке
или карточке, если названия совпадают. API-агент использует те же
[card.create/read/list/trash/restore](cards.md); UI не пишет в базу напрямую.
Весь P05.03 добавляет «Редактировать», поля «Заголовок»/«Описание»,
автосохранение и «Сохранить сейчас». Состояния «Сохраняем…» и «Сохранено»
различаются; неизвестный исход проверяется «Проверить исходное действие»
без нового ID/JSON/expected. Во время доставки новый ввод остаётся отдельным
черновиком. При stale используйте «Сверить с сохранённым»; перенос своего
текста на показанную версию — только новое явное действие.

Пустой заголовок не сохраняется; закрытие/переход предупреждают о вводе.
«Закрыть, сохранив ввод» оставляет «Черновики карточек», «Открыть черновик»
восстанавливает их после restart. «Удалить черновик» требует подтверждения
и не отменяет принятую команду. Это ввод клиента, не копия карточки/API-прав;
UI-агент работает с теми же элементами, что человек. Сменившаяся учётная запись
не получает автоматическую перепривязку прежнего черновика.

«Отметить выполненной»/«Снять отметку выполнения» задают явный bool после
подтверждения, без изменения колонки/текста/истории. Ввод сначала должен быть
сохранён. API-агент использует те же begin_editing/autosave/finish_editing/
set_completed из [cards.md](cards.md). Прямые записи в SQLite не допускаются.

UI сохраняет намерение до отправки через прежние prepare/CommandClient.
При неизвестном исходе проверяйте результат исходного намерения; не создавайте
новый ID, не меняйте expected/параметры и не подменяйте учётную запись.
«Убрать из списка» не отменяет принятую команду: используйте только как явное
завершение проверки после оценки текущих данных, с предупреждением интерфейса.
При stale обновите список и подготовьте новое явное действие после отказа;
старое намерение не получает свежую версию автоматически. Название при отказе
остаётся в открытой форме. Секреты не входят в очередь; результаты и права
не кэшируются в localStorage. Локальный черновик ввода сохраняется отдельно
от исходного намерения доставки; его нельзя объявлять подтверждённой карточкой.

Локальный Android UI — только Device. Не подделывать CI-флаг для запуска
CI-драйвера локально. Непроверенные ячейки и следующий шаг —
[EV-078](verification/EV-078-card-editor.md), предыдущие срезы — EV-077/066/064.

P05.05 добавляет «Переместить карточку» и «Переместить колонку». В диалоге
выберите колонку и «Место» («Перед: …» или «В конец»), затем «Переместить».
Ручка ⠿ доступна как кнопка с именем «Переместить: …»: короткое нажатие
открывает диалог, удержание и перенос меняют место жестом. При повторяющихся
названиях выбирайте действие внутри нужной карточки/колонки по её ID/окружению.
Для локальной Android-проверки жестов используйте Device/agent-device,
а не CDP/adb input. В CI используется штатный тестовый драйвер.

Оба способа вызывают те же `card.move`/`column.move`, что API-агент.
Версия фиксируется при открытии формы/начале жеста; перед отправкой
не подставляется более свежая. Выбор колонки/соседа не преобразуется в ранг
клиентом. При отказе или потерянном ответе доска перечитывается, исходное
намерение остаётся в штатной очереди. Подтверждённый старый receipt также
требует чтения текущей доски: позднее обратное действие не отменяется.
Возврат на прежнее место — новая команда с новой актуальной версией.
Инструкция пользователя — [moving.md](../user/moving.md), результаты —
[EV-082](verification/EV-082-board-moves-ui.md).

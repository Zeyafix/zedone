# Подключение устройств: текущая готовность

Полное подключение телефона к ПК ещё разрабатывается. В текущем срезе есть
общие административные операции создания, просмотра и отмены приглашений;
форм подключения пока нет. Создание приглашения само по себе не открывает
пространства и не начинает синхронизацию.

Приглашение действует десять минут. Его можно отменить, в том числе после
истечения срока. Для повторного приглашения создаётся новый код; старый
не восстанавливается. Приглашения сохраняются при перезапуске, срок при этом
не продлевается. Список показывает также отменённые и истёкшие приглашения.

Создавать приглашения и управлять ими может только участник с отдельными
административными правами. Обычное чтение или изменение пространств этих
прав не даёт. Секретный код не является постоянным ключом доступа.

Подготовлены защищённый канал и системное хранение его идентичности на
Windows/Android. Внутренний процесс теперь умеет принять запрос, сохранить
ожидание после перезапуска и отменить его. Пять неверных попыток блокируют
приглашение; использованный код нельзя применить повторно даже после отмены.
Отмена приглашения также отменяет ожидание. Уже принятое ожидание сохраняется
после истечения кода. До подтверждения доступа к данным и обмена нет.
Внутренний общий API теперь позволяет администратору явно подтвердить или
отклонить запрос. При подтверждении он выбирает конкретные права и срок;
ожидающее устройство не может подтвердить себя. Подтверждённое подключение
можно отвязать с любой стороны; обычный отзыв доступа также отключает его.
Пространства и история сохраняются. Для повторного подключения нужны новое
приглашение и новый ключ. Форм подключения пока нет.

Подготовлен внутренний жизненный цикл сохранённого подключения: ключ не теряется
при переходе из ожидания в подтверждённое состояние, а сбой переноса допускает
продолжение после запуска. Очистка секретов требует свежего подтверждения отмены,
отклонения или отвязки. Ошибка связи не удаляет подключение и не создаёт новое.
Внутренний процесс теперь связан с приложением Android и общим защищённым API:
подключение сохраняется после перезапуска, а отзыв или истечение прав прекращает
доступ к данным. Истечение прав само по себе не отвязывает устройство.
Повторное подключение использует новый код и ключ; прежний код не оживает.
Формы для этих действий и обмен пространствами ещё разрабатываются.

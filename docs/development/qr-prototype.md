# Генерация QR P01.08

`qrcodegen = 1.8.0` закреплён в общем Rust crate и Cargo.lock.
`core/src/qr.rs` описывает `QrRequest { text }`, `QrResponse { modules }`,
`QrError` и OpenAPI. `POST /prototype/qr` и Android IPC `qr` вызывают одну
функцию без хранения, сети, подключения устройств или выдачи прав.
Это кодирование непрозрачной синтетической строки, не продуктовый протокол.

Используются байты UTF-8 с ECI 26, Medium ECC с автоматическим повышением
без увеличения версии, версии 1–40 и автоматическая маска. Нет нормализации,
обрезки или переключения на другой способ передачи. Предварительная граница
2953 байта исключает заведомо невозможное выделение сегмента; точную вместимость
при выбранном ECC/ECI проверяет библиотека. В этом профиле помещаются 2330 байт,
2331 уже нет; это свойство кодирования, не продуктовый лимит приглашения.
Ошибки Axum для неверного JSON/полей/Content-Type остаются стандартными,
невместимость возвращает HTTP 422 с JSON `"too_long"` или тот же IPC error.

`client/QrCode.vue` — общий модуль матрица → SVG. Он строит только числовые
координаты; исходный текст никогда не вставляется в SVG/HTML. Белое непрозрачное
поле занимает четыре модуля со всех сторон, модули чёрные, масштаб целый,
`shape-rendering="crispEdges"`. Размер SVG фиксирован относительно матрицы;
контейнер прокручивается вместо обрезки/автоматического уменьшения.
`client/Qr.vue` управляет вводом, масштабом и производным результатом;
изменение текста сбрасывает устаревший QR. Ошибка сохраняет ввод, повтор явный,
HTTP/IPC ожидают не более пяти секунд. Поздний ответ не меняет UI.

После изменения контракта из `prototypes/`:

```sh
bun run generate:openapi
bun run generate:types
bun run check
bun run check:http
bun run android:build
bun run android:build aarch64
bun run check:android
```

Окружение и `PROTOTYPE_BROWSER_PATH` описаны в [общей инструкции](prototypes.md),
SDK/AVD/`ANDROID_SERIAL` — в [инструкции APK](android-prototype.md).
Новая Rust-зависимость предварительно загружается `cargo +1.99.1 fetch --locked`,
JS — `bun install --frozen-lockfile`. Дальнейшие Rust-проверки работают offline.

`scripts/qr-scenarios.mjs` входит в существующие desktop/Android runners.
Независимый jsQR 1.4.0 декодирует матрицу и PNG реального SVG, pngjs 7.0.0
читает снимки только в проверках; в runtime приложения они не включаются.
Проверяются пустая строка, синтетический адрес/код, Unicode/составной символ,
HTML как данные, NUL, 1000/2330 байт, точное HTTP/IPC-равенство,
поля/масштаб/прокрутка, неверные аргументы, отказ без обрезки, ошибка транспорта,
повтор и очистка. Это программное чтение изображения, не приёмка камеры:
Tauri Barcode Scanner и чтение с экрана ПК остаются в P01.09.

Результаты и ограничения — [EV-021](../agent/verification/EV-021-qr-generation.md).
Полная приёмка T02/A51, физический телефон и производительность не закрываются.

Источники: [qrcodegen 1.8.0](https://docs.rs/qrcodegen/1.8.0/qrcodegen/),
[четыре модуля поля DENSO WAVE](https://www.qrcode.com/en/howto/code.html),
[jsQR](https://github.com/cozmo/jsQR).

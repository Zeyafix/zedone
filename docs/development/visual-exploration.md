# Визуальная проработка: исходный Графит

По последнему решению разработчика оставлен только исходный «Графит».
Все другие направления первого раунда и шесть продолжений удалены.
[Главный HTML](../../design/visual-direction-01/index.html) автоматически открывает
[исходный макет](../../design/visual-direction-01/02-graphite/index.html).
Сервер, сборка и сеть не нужны; структура папок должна сохраняться, поскольку
оригинал использует `shared/demo-data.js`.

Исходный HTML сохранён побайтово, включая его адаптацию ПК/Android,
семантические элементы управления, обратимые действия и единое состояние.
Описание — в [README](../../design/visual-direction-01/02-graphite/README.md).
Данные остаются в памяти, реальные пространства/API/SQLite не затрагиваются.
Адаптивная мобильная компоновка не является проверкой Android Device/APK/WebView.

EV-059, EV-060 и записи журнала сохраняют результаты прежних раундов как историю,
а не текущий состав файлов. Исходники, изолированные копии в рабочем `temp/`,
снимки и inline-каталог удалённых продолжений убраны. Итог выбора — LOG-286.
Дальнейшее изменение или перенос дизайна в продукт требует отдельного поручения.

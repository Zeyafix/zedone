# EV-088 — диагностика отказа версии Android CLI

Дата: 2026-11-14. Шаг: CI.05. Состояние: in_progress.

## Карточка шага

- Цель: при отказе обязательной проверки версии Android CLI сохранить ожидаемое
  и фактическое значение и разрешённую команду, чтобы установить причину CI-сбоя.
- База: PR #87/head e4f24a3, ветка `feat/p05-09-card-history-ui`.
  Три исходных dirty документа публикации сохранены локально.
- Зависимость: CI.04 интегрирован; P05.09 локально verified по EV-087.
- Scope: `scripts/check-android-environment.sh`, этот отчёт и журнал/очередь.
  Продукт, UI/контракт/данные, версии/SHA-256 загрузок, состав проверок,
  таймауты и CI-матрица не меняются.
- Проверки: Bash syntax; реальный preflight на ограниченных подставных командах:
  верная версия проходит к проверкам SDK, другая/пустая/многострочная версия
  отклоняется с точными значениями, ошибка команды сохраняет ненулевой исход.
  Новый Android CI должен предоставить реальные значения на runner.
- Обратимость: изменение только read-only диагностики; исходные пользовательские
  операции/данные не затрагиваются. Старое поведение остаётся доступно в базе.
- Отказ: mismatch по-прежнему останавливает проверку, ни версия, ни диапазон
  разрешённых значений не расширяются.
- Результат: первоначальные product-native/product-arm64/prototype-native
  jobs, а также prototype-ui PR #87 остановились на одинаковом
  `Unexpected Android CLI version` до runtime-наборов. В прежнем PR #86
  та же проверка прошла с тем же pin/архивом; это не доказывает текущую причину.
- Далее: прочитать ожидаемое/фактическое значение нового CI, исправить
  доказанную причину отдельной правкой, затем получить все 17 SUCCESS/readiness.

Связь: GAP-024, T16/T08. Локальные сырые логи и результаты окружения
хранятся только в игнорируемой `docs/reports/p05-09/`.

## Локальный результат

Bash syntax и выполнение настоящего скрипта с подставными командами passed:
matching версия допускается к последующим SDK-проверкам, wrong/empty/multiline
строки и ошибка чтения CLI строго отклоняются с пригодными для разбора данными.
Host/Android routing guards passed. ShellCheck и фактические значения Linux
runner ожидаются в новом CI. Повторные локальные UI/Device-наборы не нужны:
продукт и UI после EV-087 не менялись. Ни root cause, ни runtime CI ещё не приняты.

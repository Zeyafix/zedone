# Срок доступа и повтор действия

Агент на ПК может работать непосредственно с данными открытого приложения
Android до синхронизации. В настройках телефона включите приём подключений
на его адресе Tailscale и выдайте агенту отдельный доступ к нужным пространствам.
В форме первоначально выбраны чтение и срок «До отзыва»; изменение требует
явного выбора и подтверждения. Отзыв и ограниченный срок действуют на телефоне
так же, как при работе через интерфейс. Данные при отзыве сохраняются.

После закрытия процесса Android соединение может стать недоступным.
Ошибка соединения не означает, что пространства или карточки удалены.
Откройте приложение и проверьте подключение; исходное неподтверждённое
действие можно повторить без создания дубликата. Наличие локальной копии
на ПК не означает, что агент обращается к актуальным данным телефона.

Ядро ZeDone проверяет разрешение при каждом обращении, включая повтор ранее
выполненного действия. Отозванный или истёкший ключ больше не разрешает доступ.
Чтобы продолжить работу после истечения или отзыва, нужно новое явное разрешение.

Администрирование и доступ к конкретным пространствам могут принадлежать
одному субъекту. Административный доступ сам по себе не открывает содержимое
других пространств; точный доступ к данным можно снять, сохранив управление
устройствами и разрешениями.

Любой субъект с действующим доступом, включая администратора, может создать
пространство и получить чтение и изменение только нового пространства.
Отдельное право создания не требуется. Команды API реализованы в P04.01.2;
пользовательские экраны относятся к P05. Подробнее — [пространства](spaces.md).

Если календарные часы устройства ушли назад за уже наблюдённое календарное
время, операции временно недоступны. Время устройства должно достичь сохранённой отметки, затем можно
повторить исходный запрос. Если ранее были ошибочно установлены далёкие будущие
часы, простого возврата к сегодняшней дате недостаточно: сброс защиты относится
к [отдельному аварийному восстановлению](emergency-recovery.md), для которого
нужны собственные служебные полномочия.
Перезапуск приложения не сбрасывает сохранённые отметки времени.
Растущие календарные часы не считаются откатившимися из-за
расхождения с отсчётом прошедшего времени. Остановка календаря не
останавливает истечение прав; уже истёкший доступ не оживает после перезапуска.

При потере ответа действие уже могло сохраниться. Клиент делает до трёх
попыток с тем же запросом. Если подтверждения нет, запрос остаётся незавершённым:
явный повтор уточняет прежний результат, не создаёт ещё одно действие.
Результат повтора подтверждает прежнее выполнение; более поздние изменения
он не отменяет. Отказ из-за устаревших данных требует перечитать состояние
и явно подготовить новое действие.

Это поведение общее для ядра, API и интерфейса. Управление доступами и
ручным подключением находится в настройках; нужен отдельный административный доступ.

Общий API теперь позволяет администратору выдать доступ к явно выбранным
пространствам, изменить права с новым ключом и просмотреть список разрешений.
Доступ с чтением не позволяет менять данные; административные полномочия
выдаются отдельно. При смене прав все прежние ключи перестают действовать.
После истечения или отзыва требуется новая явная выдача с новым ключом.
Последнего бессрочного администратора можно заменить другим администратором,
после чего снять прежние полномочия. Эти действия не удаляют локальные данные.

В «Настройки» → «Запросы и доступы» нажмите «Выдать доступ». Получатель заранее
готовит и сохраняет новый ключ, передавая только ID и проверочное значение.
Секретный ключ в форму не вводится. Явно выберите пространства: чтение и срок
«До отзыва» стоят по умолчанию. Для записи, администрирования или ограниченного
срока включите соответствующие поля и подтвердите выдачу.

«Заменить доступ новым ключом» выдаёт новое разрешение тому же получателю,
с новым проверочным значением; прежние ключи не работают. «Отозвать доступ»
прекращает действие разрешения без удаления данных. Незавершённая команда
доступна для исходного повтора. «Убрать из списка» требует подтверждения и
удаляет только запись доставки; выполненное действие не отменяется.
[Ручное подключение устройств](device-pairing.md) использует те же права.

В [Quick Start](../../development/quick-start-windows.md#3-подготовьте-android-p0003) добавлены официальные источники, закреплённая база Android-инструментов, ZIP-установка Studio и Command-line Tools с проверкой SHA256, пользовательские переменные и команды Android CLI для SDK/NDK. SDK Platform 37.0 соответствует текущему шаблону Tauri CLI; проверка APK и итоговое закрепление Gradle/AGP относятся к P01. Источники и ограничения версий указаны в самой инструкции.

Tools 23 передаёт управление SDK в Android CLI. Инструкция использует его прямые команды с именами пакетов через `/` и дополнительно проверяет файлы каждого пакета: устаревшая обёртка `sdkmanager` может вернуть `0` при сообщении `Package ... not found`. Для `avdmanager` сохранён его формат идентификаторов с `;`. Метрики Android CLI отключаются флагом вызова; авторизация Google и установка дополнительных навыков не нужны.

Проверка среды включает линковку Rust через NDK, отдельный Android 13 AOSP AVD, проверку WHPX, ограниченное ожидание загрузки, адресацию adb по serial, версию Android/API/ABI, отсутствие Google Play Services, выполнение синтетического Rust-примера и штатное завершение собственного эмулятора. Занятая пара портов требует выбора свободной пары, без остановки других эмуляторов. Описаны обратные действия для установленных инструментов, переменных и WHP.

Проверки документации: синтаксис всех PowerShell-блоков, локальные Markdown-ссылки, структура блоков Markdown, сохранность 98 критериев и `git diff --check`. Инструкция задаёт общие команды; отчёты, пути и результаты конкретной машины остаются только в игнорируемой `docs/reports/`; актуальное размещение и отделение временных файлов закреплены в [EV-006](EV-006-local-reports-layout.md), LOG-079. Эта запись не принимает T14 и не меняет состояния машинных строк P00.

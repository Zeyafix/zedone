# Прототип доски

Доска проверяет перемещения на синтетическом пространстве A. Для запуска
используйте [инструкцию прототипа](../development/prototypes.md) или
[Android APK](../development/android-prototype.md). Реальные задачи сюда пока не вносите.

1. Нажмите «Создать / открыть доску A». Существующие данные сохраняются.
2. Перенесите карточку за ручку ⠿ внутри колонки или в другую колонку.
   За ручку возле названия колонки можно изменить порядок колонок.
   На телефоне сначала удерживайте ручку около четверти секунды.
3. Прокручивайте список за текст карточки, доску — по горизонтали. При переносе
   к краю списка или доски включается автоматическая прокрутка.
4. Для перемещения без жестов нажмите «Переместить» у нужного объекта.
   Выберите колонку и позицию карточки либо позицию колонки. Кнопка «Отмена»,
   Escape и «Назад» Android закрывают окно без изменения данных.
5. «Отменить перемещение» выполняет обратную команду для последнего
   подтверждённого переноса. Любой объект также можно явно переместить обратно.

Сохранение подтверждается только сообщением «Перемещение сохранено».
При отказе или потере ответа доска перечитывает сохранённое состояние.
Если перечитать его не удалось, новый перенос недоступен: нажмите
«Перечитать доску» после восстановления доступа. Не считайте потерю ответа
доказательством отмены перемещения.

Изменение доски другим клиентом может сделать открытое представление устаревшим.
Такой перенос отклоняется; после перечитывания выберите действие заново.
Порядок сохраняется после перезапуска. Для удаления и восстановления набора
используйте [снимок и команды SQLite-прототипа](prototype-storage.md).
Те же операции доступны агенту через общий API.

# Работа с синтетическим SQLite-прототипом

Это экспериментальная форма для проверки хранения. Используйте только
синтетические данные A/B; полноценные пространства ZeDone ещё не реализованы.
Запуск описан в [инструкции разработчика](../development/sqlite-prototype.md).

1. Выберите A или B и нажмите «Создать набор»: появятся три колонки и 30 карточек.
2. Введите запрос и нажмите «Прочитать / найти». Очистите запрос и прочитайте
   снова, чтобы увидеть все карточки. Поиск не меняет сохранённый набор.
3. Нажмите «Снимок», чтобы сохранить полное состояние выбранного набора в форме.
4. «Удалить набор» удаляет выбранное пространство; «Восстановить снимок» возвращает
   пространство, указанное в сохранённом снимке. Другой набор сохраняется.

Наборы остаются в БД после перезапуска HTTP-процесса или Android-приложения.
Снимок в форме исчезает при её перезагрузке: это не автоматическая резервная
копия. Перед удалением сохраните нужный снимок; агент может сохранить JSON через
тот же API и восстановить его позже.

Если результат не подтверждён, сначала прочитайте данные: ошибка связи не
означает, что изменение отменено. Автоматического повтора изменения нет.
Форма echo продолжает работать независимо от ожидания SQLite и не хранит свой
текст. Удаление APK удаляет его синтетическую базу.

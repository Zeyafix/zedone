# EV-071: единая стартовая схема до завершения плана

Дата: 2026-11-07. Шаг: DEV.01. База: e092e3b (runtime e6bf604).
Ветка: `refactor/single-initial-schema`.

## Рабочая карточка

- Основание: прямое поручение разработчика — поддерживать прошлые версии
  только после реализации всего плана; сейчас свести базу к одной стартовой версии.
- Цель: новый и повторный запуск используют единственную схему v1 со всеми
  текущими возможностями; прежние базы разработки не мигрируют и не сбрасываются.
- Охват: SQL/реестр/валидация прав, связанные тесты и эталон, политика в docs.
  Общая инфраструктура безопасных миграций остаётся, её цепочки — синтетические.
- Превышение ориентира 300 строк обусловлено одной сменой базовой схемы:
  её реестр, исторические тесты и инструкции должны измениться согласованно.
- Проверки: полный Windows product-check, native Android x86_64 product-check,
  release обеих Android ABI, unsafe guard и контракт; отказ старым схемам без
  записи, повторное открытие/обратные действия/receipt и crash/restart матрица.
- UI не меняется; визуальная проверка не требуется. Данные установок не удалять.

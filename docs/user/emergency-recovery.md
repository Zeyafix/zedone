# Служебный режим и восстановление всей базы

Если целостность базы не подтверждена, ZeDone останавливает работу с
пространствами и обмен. На служебном экране указана причина. Проблемные файлы
сохраняются отдельно; они не считаются исправной резервной копией.

Если схема базы не поддерживается этой версией ZeDone, служебный экран
предлагает установить подходящую новую версию. Приложение не сбрасывает и
не понижает схему, не открывает её только для чтения. Данные базы сохраняются;
работа с пространствами и обмен недоступны. После устранения причины нажмите
«Повторить запуск». Повтор с прежней неподходящей версией сохранит отказ.
Если попытка осталась в списке незавершённых действий, после устранения
причины используйте «Повторить исходную команду».

После устранения причины можно явно повторить запуск. ZeDone не заменяет
базу из копии автоматически. Для аварийного восстановления нужна полная
предмиграционная копия, включающая базу и снимки пространств. Обычный снимок
одного пространства для этой операции не подходит.

1. Выберите папку с полной копией; на Android используется системный выбор
   локальной папки. Отмена выбора ничего не меняет.
2. Выберите копию и нажмите «Проверить копию». База пока не заменяется.
3. Прочитайте дату, число пространств и последствия замены всей базы.
   Для замены отметьте подтверждение и нажмите «Восстановить всю базу».
   Подготовку можно отменить.
4. После успеха отдельно откройте пространства. Прежние ключи отключены,
   подключения нужно подтвердить заново, обмен остаётся на паузе. Папку
   автоматических копий выберите заново с правом управления. Старые файлы
   копий сохраняются и доступны через каталог выбранной папки.

Пока пространства не открыты, можно вернуть сохранённое проблемное состояние.
Это возвращает исходные файлы и оставляет работу остановленной. Исправные
копии остаются на месте. Ненужное сохранённое состояние удаляется отдельным
действием с подтверждением; после удаления вернуть его через ZeDone нельзя.

Если операция прервалась, обычная работа остаётся закрытой. Повторите исходную
команду; владелец также может явно подтвердить продолжение. При неизвестном
результате не создавайте новое действие вместо сохранённого запроса. Удаление
запроса из списка не отменяет уже выполненную замену.

В настройках можно явно перейти в служебный режим и вернуться через повторный
запуск. Здесь же владелец выдаёт и отзывает отдельный служебный доступ агенту.
По умолчанию он разрешает только чтение сведений. Право восстановления всей
базы выдавайте отдельно; обычный ключ работы с пространствами его не даёт.

# Разрешение названий пространств и колонок

Прочитать `space.read` или `column.read`; конфликт имени представлен несколькими
значениями `names`. Не использовать обычное `rename` для его перезаписи.

Команды `space.resolve_name` и `column.resolve_name` принимают `space`, `name`,
`expected` из прочитанного `version`; колонка дополнительно принимает `column`.
Действуют обычные envelope `id`/`operation`, HTTP `/v1/commands/<operation>`,
CLI `--operation <operation>` и IPC. Требуется действующее право изменения
пространства. Возвращается тот же snapshot, ID и содержимое сохраняются.
Пустое имя допустимо, одинаковые имена разных объектов не объединяют их.

Команда разрешает только существующий конфликт имени активного контейнера.
Нерешённое состояние удаления контейнера блокирует её; именование не разрешает
конфликт места колонки. Обычные изменения самого спорного контейнера закрыты,
работа с его содержимым разрешена с учётом собственных конфликтов объектов.

`stale_state` требует перечитывания и нового явного решения. Нельзя автоматически
подменять `expected` в прежней команде. При неизвестном исходе повторять исходные
байты и `id`: прежний результат не отменяет позднюю правку. Текущие права
проверяются и для повтора. Независимые разные решения остаются новым конфликтом
после обмена; выбрать снова только после чтения актуального состояния.

Прежние варианты сохраняются техническим графом; отдельной команды возвращения
разрешённого конфликта нет. Название после решения можно изменить обычным
переименованием. Поля карточек — отдельный P06.05.2.

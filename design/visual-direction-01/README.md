# Исходный Графит

По решению разработчика сохранён только исходный «Графит». Все альтернативы
и продолжения удалены. [Главный HTML](index.html) автоматически открывает
[исходный макет](02-graphite/index.html).

Исходный `02-graphite/index.html` не изменён. Для открытия без сервера и сети
сохраните структуру папок: макет использует [shared/demo-data.js](shared/demo-data.js).
План, палитра, действия и ограничения — в [README Графита](02-graphite/README.md).

Один адаптивный HTML работает на ПК и в мобильной компоновке. Поиск, просмотр,
редактирование с отменой, создание, удаление и восстановление карточек сохраняются.
Состояние находится в памяти страницы; перезагрузка возвращает исходные данные.
Продуктовый API, SQLite и синхронизация не подключены. Нативный Android не проверялся.

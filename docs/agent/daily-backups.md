# Ежедневные резервные копии через общий API

Windows и открытый Android APK используют одни и те же команды HTTP/CLI/IPC.
Источник форматов — Rust/OpenAPI, а не содержимое SQLite или каталогов.
Работающий host сам проверяет условия после старта/сохранения/смены дня.

| Операция | Параметры | Права |
| --- | --- | --- |
| `space.backups.inspect` | `space` | Чтение пространства |
| `space.backups.read` | `space`, `copy` из `copies[].id` | Чтение пространства |
| `space.backups.retry` | `space`, `failed_sequence` из последнего inspect | Чтение/изменение |
| `space.backups.delete` | `space`, `copy` из списка | Чтение/изменение |

Inspect возвращает `status`, `copies`, `last_success`, `failed_sequence`,
`retry_after_ms` и `cleanup_pending`. Последний успех сохраняется и после
удаления его файла; доступность определяется списком `copies`. Нет файловых
путей или настроек часов в параметрах. Read возвращает обычный `SpaceArchive`;
его можно сохранить или передать [восстановлению пространства](space-recovery.md).
Чтение и выбор копии сами по себе не запускают восстановление.

Retry после ошибки обходит только автоматическое ожидание: изменения,
дневной лимит и права проверяются заново. Устаревший номер ошибки не создаёт
новую попытку; актуальное состояние перечитывается через inspect. После
новой ошибки нужен новый явный запрос с новым номером ошибки. Повтор доставки
прежнего запроса использует прежние ID и байты; receipt возвращает исходный
результат, а не текущее состояние. Отзыв/истечение доступа запрещают и replay.

Delete требует явного намерения на указанную копию. Дневной лимит не
сбрасывается. Физическое удаление может ожидать восстановления доступа к
папке; `cleanup_pending` не означает откат действия или потерю остальных файлов.
Нельзя вручную менять служебные записи, конструировать имена каталогов или
включать старые файлы в состояние базы. [Общие правила повторов](command-retries.md).

Политика и публикация: [ADR-0080](../architecture/decisions/0080-daily-backup-publication.md).
Приёмка: [EV-157](verification/EV-157-daily-backups.md). Выбор папки и каталог
копий без прежней базы остаются P07.05; весь P07/T10 этим шагом не принимается.

Каталог без прежней базы, выбранная папка и безопасный перенос подключены
в P07.05: [каталог копий](backup-catalog.md), ADR-0081/EV-161.

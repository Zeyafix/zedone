- Требования: T05/A15/A24/S06, спецификация §1.2.4/6, §6–7 и сценарии 15/24;
  актуальность — ADR-0014, регистры полей — ADR-0002/0007.

- Охват: отдельная синтетическая фикстура пространства с колонками, карточками,
  прежней корзиной и ограниченным каталогом тегов; общий Rust/CLI-драйвер,
  тесты, документация. Продуктового формата, зависимостей и миграций нет.
- Модель: независимые регистры состояния каждого уровня; правка/создание
  атомарно подтверждают активность предков. Причинные ID удаления и отдельные
  ссылки на группу пространства/колонки сохраняют прежнюю корзину. Время
  не выбирает победителя; явный выбор не разрешает остальные конфликты.
- Проверки: Windows `bun run check`; Android
  `bun run check:automerge --android` на API 33/x86_64, сборка arm64 CLI;
  SQLite reload, отдельные процессы, повторы/перестановки/старая реплика,
  равные/разные/поздние решения, строгая актуальность и AFTER UPDATE ABORT.
- Обратимость/отказ: восстановление пространства возвращает только свою
  группу; прежняя корзина восстанавливается отдельно после пространства.
  Недопустимые/устаревшие команды и сбой не оставляют частичных изменений.

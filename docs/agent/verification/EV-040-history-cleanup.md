# EV-040 — очистка известных версий истории

## Карточка P02.05.4

- База: `4e7c5e1`, общая ветка `feat/p02-05-purge-history` по поручению
  разработчика выполнить весь оставшийся P02.05. Зависимость P02.05.3/EV-039
  реализована в этом дереве; целевые проверки пройдены, общие впереди.
- Цель: очистка истории карточки/пространства удаляет известные версии,
  сохраняя текущее содержимое, конфликты и независимые новые версии.
- Требования: T05/A16/A31, спецификация §1.2/6–7; ADR-0013 задаёт пару
  заголовок/описание. Группировка серий и доверенные участники — P03/P04.
- Оценка до кода: одна матрица причинной очистки карточки/пространства,
  конфликтов, независимых версий и атомарности. Превышение ориентира 300 строк
  обосновано проверками. Продуктового формата/новых зависимостей нет.
- Область: общий Rust/CLI/SQLite прежней изолированной иерархии; отдельные
  версии — неизменяемые Map в общей List с причинными Object ID. Список
  создаётся в исходном документе до обмена; первые независимые версии не
  создают конкурирующих корневых списков. Одна дискретная синтетическая
  правка сохраняет пару полей и версию одним изменением Automerge.
- Предварительный результат команды показывает карточку/пространство,
  известные версии, число удаляемых и сохраняемых конфликтующих версий.
  Очистка удаляет наблюдавшиеся элементы List; новые офлайн-вставки не
  входят в удаление. Версии живых конфликтующих присваиваний сохраняются.
- Проверки: текущие поля/состояния/группы без изменений; другая карточка и
  пространство; офлайн-очистка/оба порядка доставки/конкурентные очистки;
  нерешённые конфликты/неизвестная третья версия; старые повторы/перестановки;
  новая правка после очистки; прежний снимок неизменен; атомарность версии
  с содержимым и AFTER UPDATE ABORT для записи/обеих очисток/окончательной
  очистки вместе с известной историей. Финальные команды — как в EV-039.
- Обратимость: ручная очистка истории — согласованное исключение; текущие
  данные сохраняются, прежние копии не переписываются. Общая команда одна
  для человека/агента и обеих платформ; продуктовые адаптеры впереди.

тега нужно проверить вместе с сохранностью назначений, последующей обратимой

приравнивания е/ё. Полная Unicode-политика, точный набор краевых пробелов,

## Ограничения и передача

Нативный паритет проверен на Windows/Android x86_64, arm64 только собран.
Физическое устройство, новый APK/WebView, продуктовые UI/HTTP/CLI/IPC/права,
удаление тегов, полная Unicode-политика, масштаб/память не проверялись.
Причинные heads и исторические чтения являются временной моделью, стоимость
требует P02.06. Сохранённый документ SQLite — источник данных, проекция и
контрольный JSON вычисляются из него. Продуктовые критерии остаются partial.

Позднее создание может быть независимо от двух тегов, которые сами уже были
известны как разные. Транзитивное объединение тогда ошибочно слило бы известные
разные идентичности. Пробник сохраняет их по отдельности, помечает/приостанавливает
операции без потери назначений. Это консервативный охранный отказ, не принятый
продуктовый договор. Разработчик принял сохранение трёх разных тегов с явным выбором разных имён
(ADR-0012/LOG-215); реализация этого правила остаётся P02.04.2.2.2 до завершения модели тегов. В этом срезе два сценария ADR-0012
проверены только за обнаружение/сохранность/отказ; их последующие явные/конкурирующие
решения проверяет [EV-033](EV-033-tag-name-resolution.md). A52/A53 остаются partial. Предыдущий пробник P02.04.1 сохранён.

Обратные переименования/назначения, общая команда человека/агента, документация
и единый авторитетный документ подтверждены в пределах этого среза. Продуктовые
команды создания/удаления не открыты; удаление самого тега — P02.04.3 с ранее
согласованным исключением восстановления. Собственный read-only эмулятор
остановлен, временные каталоги удалены драйвером; физические устройства не менялись.
После интеграции этого среза следующий шаг — P02.04.2.2; срез интегрирован через PR #27 в 900ab8e.

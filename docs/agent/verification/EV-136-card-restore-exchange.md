## Результаты проверок

- Windows `cargo test --locked -p zedone-storage` — 313 тестов прошли,
  одна отдельная проверка производительности поиска пропущена штатным набором.
- Нативный тест x86_64 на Android API 33 прошёл в эмуляторе Device.
  На обеих платформах тест подтверждает отказ по устаревшей версии колонки
  назначения, сохранение ID и текста, повторное открытие SQLite, повторную
  доставку и восстановление только оставшейся карточки исходной группы.
- Контракт `card.restore`, UI и способ хранения прежние. Выбор назначения из
  корзины проверялся в [EV-086](EV-086-trash-ui.md). В этом срезе добавлены
  проверки обмена существующей операции.
- `bun scripts/check-pairing-app.mjs --card-restore` прошёл через TLS и CLI.
  Windows отправила колонку с двумя карточками в корзину. Android восстановил
  одну в другую колонку. После повторной доставки Windows восстановила
  исходную колонку. На обоих устройствах в ней осталась только вторая
  карточка, а в выбранной колонке была ровно одна первая карточка с прежними
  ID и текстом. Устаревший запрос был отклонён без изменения карточки.
- Исходный APK, файлы приложения и локальный debug APK восстановлены по
  SHA-256. Временные ключи и правила транспорта очищены, Device выключен.

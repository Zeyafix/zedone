- Размер больше ориентира 300 строк: один путь отказа/перезапуска/возврата

  checkpoints P07.10 сохраняются вместе с результатом, без удаления истории.

## Уточнения при проверке

- Первый адресный тест ошибочно включал SHM и отсутствие нового пустого WAL
  в durable-гарантию. SQLite создала пустой WAL/SHM при read-only preflight;
  исходная база осталась побайтово прежней. Ожидание уточнено по ADR-0035:
  отсутствие WAL frames/rollback journal после первого отказа и неизменные
  база/WAL/journal при последующих попытках; SHM — транзитные данные.
  Исходный failure сохранён в ignored reports. Product preflight не менялся.
- Проверка повторного открытия обнаружила сохранённый blocked gate:
  Storage возвращает RetryRequired до нового preflight. activate_failed
  перезаписывал им исходную UnsupportedSchema, скрывая рекомендацию после
  restart. Теперь общий storage сохраняет прежнюю причину только при уже
  закрытом gate и общем RetryRequired; новая реальная ошибка заменяет её,
  новый явный retry не наследует старую причину при новом отказе.
  Добавлены portable storage/HTTP/реальный CLI/IPC проверки перезапуска.
- Полный host-run дошёл до нового успешного retry и выявил оставшуюся старую
  причину при `normal_ready: true`. Успешный Retry с готовым Service теперь
  очищает её; исходный failure сохранён. Закрытый gate до успеха прежний.
- Первый UI main прошёл общие сценарии и остановился в новом maintenance
  случае: после ответа unavailable исходная команда остаётся незавершённой,
  поэтому новый retry недоступен. Сценарий исправлен на явный повтор прежнего
  намерения после устранения причины; ID/параметры не заменяются. Продуктовая
  очередь намерений и её запреты не менялись; исходный timeout сохранён.

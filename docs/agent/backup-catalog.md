# Каталог копий: общий API

Не сканировать и не изменять SQLite/файлы вместо команд. Для явного локального
выбора папки доступен CLI:

```text
zedone --select-backup-folder --database <db> --key-file <key> --mode read --folder <path>
zedone --select-backup-folder --database <db> --key-file <key> --mode manage --folder default
```

Команда требует действующий ключ и локальный доступ к пути; возвращает handle
папки вызывающему субъекту. `read` не предоставляет удаление или перенос.
`manage` явно охватывает выбранную и текущую папки. Android выбирает локальный
SAF tree через UI; агент использует выданный его субъекту handle через HTTP/CLI/IPC.
Сетевой API не принимает произвольный путь. Предыдущая база не нужна: новая
установка имеет собственный локальный доступ, затем явно выбирает старую папку.

| Операция | Параметры | Результат |
| --- | --- | --- |
| `backups.folders` | `{}` | handles вызывающего субъекта, label, writable |
| `backups.catalog` | `folder` | пространства/имена/даты/kind/digest и unreadable |
| `backups.catalog.read` | `folder, copy, expected: digest` | полный archive; без восстановления |
| `backups.catalog.delete` | `folder, copy, expected: digest` | подтверждённое отдельное удаление, cleanup_pending |
| `backups.location.inspect` | `{}` | текущая папка, is_default, version, cleanup_pending |
| `backups.location.change` | `folder, expected: location.version` | результат переноса/переключения |
| `backups.location.cleanup` | `expected: location.version` | завершение удаления исходников |
| `backups.folder.forget` | `folder` | отзыв handle без удаления файлов/смены расположения |

Обычный конверт `{id,operation,parameters}`, ключ отдельно. Изменения сохраняют
receipt; при потерянном ответе доставлять прежние ID/байты. Повтор не означает
текущее состояние: после него читать location/catalog. Срок/отзыв основного
доступа и handle проверяются перед чтением и изменением, включая повтор
удаления/смены папки. Отозванный handle не оживает от прежнего receipt.

Просмотр не вызывает daily tick, cleanup, импорт, восстановление, обмен,
ротацию или смену папки. Для восстановления существующего пространства
использовать отдельные [операции восстановления](space-recovery.md) с его
правами и актуальным expected. Для независимой копии — `space.import`.
Handle не даёт полномочий аварийного восстановления всей базы.

Каталог показывает прежние файлы без индекса: копии очищенного пространства
сохраняются до отдельного удаления. Полный предмиграционный комплект переносится
целиком; отдельные снимки из него можно читать, но нельзя частично удалять.
Ошибки до переключения сохраняют исходники; после переключения сохраняются
новое расположение и проверенные копии, pending cleanup требует завершения.
Посторонние файлы не удалять ради успешного повтора. Архивы/пути/ключи не
публиковать в логах. Бюджеты и технический договор — ADR-0081.

# ADR-0001: Tauri 2 как Android-оболочка

Дата: 2026-10-26.

Статус: принято разработчиком. Техническая проверка реализации ещё не выполнена.

## Контекст

ZeDone использует общий интерфейс Vue + TypeScript + Vite и Rust-ядро для Windows и Android. На Windows интерфейс открывается в браузере; на Android он поставляется внутри APK и работает с локальными данными независимо от ПК и сети.

Ранее Tauri 2 был первым кандидатом для прототипа. Разработчик явно выбрал Tauri 2 основной Android-оболочкой и указал Kotlin + WebView резервом.

## Решение

- Основная Android-оболочка — Tauri 2.
- Резерв — собственная оболочка Kotlin + Android WebView с подключением общего Rust-ядра. Она рассматривается при выявленных ограничениях Tauri 2, мешающих выполнить обязательные требования ZeDone. Основания перехода и результаты проверок фиксируются отдельным архитектурным решением.
- Основная логика, хранение и синхронизация остаются в Rust. Kotlin допустим для необходимой платформенной интеграции, в том числе при использовании Tauri.
- Для внутреннего транспорта интерфейса APK первым проверяется IPC через команды Tauri; окончательный выбор транспорта остаётся открытым до проверки. IPC и внешний HTTP на Axum должны вызывать одни прикладные операции ядра с общими правами доступа и одним авторитетным локальным хранилищем.

## Основание и последствия

Выбор сделан разработчиком после обсуждения готовой и собственной оболочек. Ожидаемое сокращение собственного кода связи и платформенной интеграции при использовании Tauri — проектная оценка; сравнительных измерений ZeDone пока нет.

Проверка P01 обязательна: сборка APK на Windows 11, запуск в эмуляторе Android 13, ввод и клавиатура, системная кнопка «Назад», перетаскивание, файлы, сохранение и повторный запуск, внешний HTTP-доступ через Tailscale и паритет прикладных операций. Проверка на Galaxy A32 рекомендована перед выпуском; эмулятор не подтверждает производительность телефона.

Принято ограничение: Tauri 2 выбран до технической проверки ZeDone. Это решение не закрывает критерии приёмки и не подтверждает совместимость всей цепочки Bun/Vue/Vite/Tauri, работу HTTP-сервера в APK или требуемую производительность. Постоянная работа сервера при закрытом APK по-прежнему не обещается.

Точная версия Tauri 2 фиксируется при подготовке прототипа. Существующие требования обратимости, общего API человека и агента, паритета платформ и запрета собственного unsafe в ядре, хранении и синхронизации сохраняются.

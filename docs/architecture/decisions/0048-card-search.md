# ADR-0048: общий поиск по текущим вариантам карточек

Дата: 2026-11-07. Статус: принято; проверка реализации — EV-072.

## Решение

Разработчик выбрал для поиска канонический полный Unicode case folding и NFC:
Café = Café, Straße = STRASSE. NFD → default full case folding → NFC выполняет
общий модуль Rust с закреплёнными ICU4X. Только у запроса обрезаются краевые
Unicode White_Space (`str::trim`). Исходное написание, внутренние пробелы,
пунктуация и различие «е»/«ё» сохраняются. Локаль и NFKC не применяются.
Это уточняет DEC-005 для поиска, не закрывая остальные вопросы.

`card.search` получает область `space` с ID либо `all`. Host явно передаёт
активное пространство; очистка запроса снимает только текстовый фильтр.
Фрагмент ищется отдельно в каждом текущем заголовке/описании, включая
конфликтующие варианты. История, теги и имена контейнеров не участвуют.
Выполненные карточки включаются, однозначная корзина исключается.

Ответ сгруппирован по пространствам с совпадениями. `sort_spaces` общая с
`space.list`: конфликт имён первым, иначе Unicode lowercase имени, исходное
имя и ID. Поиск не меняет существующее сравнение имён. Внутри пространства
спорное место или удаление карточки/контейнера выделяется перед обычными
результатами, с устойчивым порядком по ID карточки. Обычный порядок —
`Rank::key` колонки, ID колонки, `Rank::key` карточки, ID карточки.
Спорный вариант места не выбирается. Конфликт только текста/названия не
меняет однозначное место карточки. Карточка возвращается один раз.

Поиск читает авторитетные снимки `CardStore` в обычной авторизованной
транзакции. Индекса, отдельного хранилища и миграции схемы нет. Тот же ID
возвращает сохранённый receipt, новый ID выполняет свежий поиск. При повторе
заново проверяются права на каждое возвращаемое пространство: сужение прав
отклоняет весь старый результат, включая имена и тексты, с `access_denied`.

## Проверка и границы

HTTP/CLI/Tauri IPC используют общий Service и производные Rust/OpenAPI-типы.
Проверяются Unicode, буквальность, поля/варианты, области/права/replay,
порядок/конфликты, сбой receipt и перезапуск. Проба нагрузки не заменяет P09.
UI поиска — P05.07, продуктовые синхронизация/разрешение конфликтов — P06.
Поиск не меняет карточки, историю и позиции; запрос можно изменить/очистить.

# Работа агента с оболочкой

Навигация доступна ссылками «Пространства»/«Настройки», на телефоне — в «Меню».
Тема выбирается radio-группой «Тема»: «Как на устройстве», «Светлая», «Тёмная».
Человек и UI-агент используют те же элементы. Это локальное предпочтение
представления, не прикладные данные.

Проверка доступа выполняет `space.list` через тот же Service и права, что
описаны в [spaces.md](spaces.md). Запущенный APK, session-файл и HTTP 200 сами
по себе не доказывают авторизацию. Секрет не выводить и не сохранять в
URL/pending/localStorage/отчёты. Проверка не выдаёт полномочий и не меняет
предметные данные.

Управление пространствами и колонками подключено к общему API (P05.02).
UI-агент использует «Создать пространство», ссылку с названием пространства,
«Создать колонку», «Переименовать», «В корзину», «Корзина»/«Активные» и
«Восстановить». Формы Reka Dialog имеют поле «Название», явное подтверждение
и отмену. На Android Back закрывает форму до выхода из пространства.
Пустое название показывается как «Без названия»; при нескольких одинаковых
названиях выбирайте действие в строке/колонке нужного объекта.

Прикладной агент выполняет те же space/column команды через HTTP/CLI/IPC;
[пространства](spaces.md), [колонки](columns.md). Не заменять UI прямой записью
в SQLite. Неизвестное содержимое и конфликты сохраняют отказы общего ядра.
`shell_session`/`/host/session` —
внутренний порт доставки ранее выданной учётной записи, не обход guard.

UI сохраняет намерение до отправки через прежние prepare/CommandClient.
При неизвестном исходе проверяйте результат исходного намерения; не создавайте
новый ID, не меняйте expected/параметры и не подменяйте учётную запись.
«Убрать из списка» не отменяет принятую команду: используйте только как явное
завершение проверки после оценки текущих данных, с предупреждением интерфейса.
При stale обновите список и подготовьте новое явное действие после отказа;
старое намерение не получает свежую версию автоматически. Название при отказе
остаётся в открытой форме. Секреты не входят в очередь; результаты и права
не кэшируются в localStorage.

Локальный Android UI — только Device. Не подделывать CI-флаг для запуска
CI-драйвера локально. Непроверенные ячейки и следующий шаг —
[EV-066](verification/EV-066-space-column-ui.md), исходная оболочка — EV-064.

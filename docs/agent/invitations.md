# Приглашения подключения

P06.01.2.1 предоставляет только административную подготовку приглашения.
Она не подключает устройство и не выдаёт ему прав. Запрос/подтверждение,
защищённый канал и формы остаются следующими шагами.

Всем четырём `invitation.*` требуется административный доступ. Доставка
общая: HTTP `/v1/commands/<operation>`, IPC `zedone_command` и CLI
`--operation <operation>`, как в [работе с доступом](access.md).
Нельзя писать напрямую в SQLite или считать сам код ключом доступа.

1. Вызвать общий `newInvitation()`, сохранить `code` отдельно в защищённом
   хранилище host до отправки. Он не входит в pending intentions и журнал.
   Сохранить invitation/verifier вместе с исходным намерением создания.
2. `invitation.create` принимает `{invitation, verifier}`. Срок — десять минут
   от первой успешной команды; произвольный срок/исходный код не принимаются.
3. `invitation.inspect` принимает `{invitation}`. Ответ: invitation,
   created_at_unix_ms, expires_at_unix_ms, status (open/expired/cancelled), version.
   Отсутствующая запись — not_found только после проверки полномочий.
4. Для отмены получить свежий снимок и отправить `invitation.cancel`
   с `{invitation, expected: version}`. При stale_state нужен новый просмотр
   и новая явная команда, без подмены expected старого намерения.
5. `invitation.list` принимает `{after:null}` или исключительный ID из next,
   выдаёт entries (до 50) и next. Новые чтения требуют новых command ID.

Отмена/истечение не позволяют переиспользовать ID или проверочное значение.
Для нового приглашения генерируются новые ID/код. Replay возвращает исходный
статус без продления срока/восстановления отменённого приглашения. Даже успешный
receipt create с open не подтверждает текущую пригодность приглашения.
Отозванный/истёкший административный доступ не получает старые receipts.

Код не следует передавать через чат, argv или обычный JSON API. Секрет остаётся
отдельно; его безопасные показ и доставка будут реализованы вместе с каналом.
Сейчас не пытаться подключать неподтверждённое устройство этим кодом.
Подробности: [ADR-0054](../architecture/decisions/0054-persistent-pairing-invitations.md).

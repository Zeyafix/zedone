# Колонки

Колонка принадлежит пространству. Сейчас общий API позволяет создать пустую
колонку, прочитать/перечислить колонки, переименовать, отправить в корзину
и восстановить. Формы управления и изменение порядка доступны в интерфейсе.
[Карточки](cards.md) доступны через общий API и общий редактор.

Названия сохраняются точно, включая пробелы, Unicode и пустую строку.
Одинаковые названия не объединяют разные колонки. Новая колонка добавляется
в конец; восстановление сохраняет исходное место. Корзина сохраняет данные
и идентичность колонки. Переименование можно отменить новой обратной правкой.

Если колонка изменилась после чтения, старая команда отклоняется целиком.
Нужно перечитать состояние и явно выполнить действие заново. Изменение
соседней колонки само по себе не отклоняет действие над выбранной.
Если ответ потерялся, повтор исходного запроса проверяет прежнее выполнение,
не дублирует колонку и не отменяет более позднее восстановление.

Доступ определяется правами пространства. В пространстве в корзине новые
изменения колонок запрещены. Через общий API колонка отправляется в корзину
вместе со всеми её активными карточками. Перед действием можно прочитать
колонку с составом и данными карточек. Изменение состава, текста, тегов,
выполнения или положения после чтения отклоняет всё действие.

Восстановление возвращает колонку и только карточки, удалённые вместе с ней.
Ранее удалённые карточки остаются в корзине. Текст, теги, выполнение, порядок
и история сохраняются; незавершённая сохранённая серия текста фиксируется
при удалении. Если у одной из карточек есть конфликт, вся операция
отклоняется. Неизвестное содержимое также блокирует действие.

Формы интерфейса управляют также колонками с содержимым: перед действием
показаны карточки группы и прежняя корзина. Удаление пространства с содержимым
и отдельное восстановление карточки в другую колонку доступны через тот же API
и интерфейс. Окончательная очистка
описана в [инструкции корзины](cleanup.md).


Через общий API можно переставить колонку перед другой колонкой пространства
или в конец, затем вернуть обратно. Её карточки сохраняются вместе с ней;
их данные и порядок внутри колонки не меняются. Новое положение сохраняется
при перезапуске и корзине/восстановлении. В интерфейсе доступны
[перетаскивание и выбор места](moving.md).

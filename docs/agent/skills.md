# Agent skills

The maintained source for project skills lives in `.agents/skills/`.

- [ze-commit](../../.agents/skills/ze-commit/SKILL.md) helps agents write and create Conventional Commits with clear English messages.
- [ze-pr](../../.agents/skills/ze-pr/SKILL.md) helps agents prepare and publish English pull requests with clear outcomes, before/after UI evidence, and testing results.
- [frontend-design](../../.agents/skills/ze-frontend-design/SKILL.md) guides distinctive interface design, typography, visual direction, and meaningful copy.

Invoke a skill with `$ze-commit`, `$ze-pr`, or `$frontend-design`. Each linked `SKILL.md` is the authoritative source for that skill's instructions.

# Просмотр Markdown в прототипе

В форме echo введите синтетический Markdown и нажмите «Отправить». Ниже
неизменённого ответа появится форматированный просмотр. Текст не сохраняется
после закрытия процесса: это проверка технологий, а не редактор карточек.

Поддерживаются заголовки, выделение, списки, ссылки, цитаты и код по CommonMark.
HTML-теги видны как текст. Таблицы и интерактивные чекбоксы не добавляются;
их маркеры остаются в тексте.

HTTP/HTTPS-ссылка открывается по нажатию в отдельной вкладке браузера ПК или
во внешнем браузере Android. Экран прототипа остаётся открытым. Остальные
адреса в этом прототипе не активируются.

Изображения сначала показаны описанием и кнопкой «Загрузить изображение».
Каждое загружается отдельно, только после нажатия. «Скрыть изображение» убирает
его из просмотра. После ошибки проверьте сеть/адрес и нажмите «Повторить загрузку»;
текст остаётся доступным для чтения и изменения. Новая отправка текста сбрасывает
разрешения на загрузку. «Очистить» убирает ввод, ответ и просмотр.

Ошибка открытия браузера или загрузки изображения не меняет исходный Markdown.
Человек и агент используют тот же echo API; форматированный HTML не сохраняется.

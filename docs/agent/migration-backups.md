# Предмиграционный комплект

P07.07.1 предоставляет доверенную инфраструктуру подготовки, ещё без команды
пользователя/агента. `Storage::prepare_migration_backup(folder, date, limits)`
создаёт отдельный кандидат в существующей выбранной папке: полную SQLite-копию
со служебными записями и снимки всех пространств из того же состояния.
`PreparedBackup::verify(limits)` повторно читает и проверяет комплект;
`discard` явно удаляет только этот кандидат. Drop/потеря ответа сохраняет его.
Методы verify/discard синхронны и вызываются инфраструктурой вне async-потока UI.

Не вызывать низкоуровневую инфраструктуру как способ обойти core/полномочия.
Полная база содержит все пространства и локальные служебные данные; доступ
только к одному пространству не разрешает эту операцию. Папка должна быть
приватной. Хеши проверяют повреждение, не доверие или разрешение на откат.

Указать бюджеты базы, числа пространств, суммы архивов и каждого снимка;
недоступная папка/ошибка/превышение бюджета останавливает текущую попытку,
другого места сохранения автоматически нет. Старые копии и исходник сохраняются.
Не удалять старые копии вручную ради освобождения места в процессе подготовки.

Кандидат **не разрешает миграцию**: после возврата writer lock отпущен.
P07.07.2 должен связать новый захват и попытку миграции без промежутка для записи,
безопасно опубликовать результат и обработать незавершённые каталоги. P07.08
ожидает весь P07.07. Не принимать каталог или манифест за признак успешной
миграции; автоматического восстановления нет. Проверки и границы —
[EV-050](verification/EV-050-pre-migration-backup-candidate.md) и
[ADR-0033](../architecture/decisions/0033-pre-migration-backup-candidate.md).

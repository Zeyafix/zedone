# EV-037 — колонка: корзина и группа удаления

## Карточка P02.05.2.1

- База: `10623c0d689cea64d96d56985487e76a253cdb58`, чистая актуальная main.
- Зависимость: P02.05.1/EV-036, PR #31 head `efb06a5`, merge `10623c0`;
  три финальные Windows/Linux/Android PR checks SUCCESS, ветка удалена.
- Цель: сохранить правки и новые карточки при независимом удалении колонки,
  явно выбрать корзину либо восстановление с корректной группой удаления.
- Требования: T05/A15/A24/S06, спецификация §1.2.4/6, §6–7, сценарии 15/24;
  локальная актуальность удаления — ADR-0014, поля карточки — ADR-0007.
- Оценка до кода: P02.05.2 разделён на .1 колонку и .2 пространство.
  Пространство с вложенными группами и предварительным восстановлением —
  самостоятельная матрица следующего среза. В .1 операция/обратная операция,
  оба решения, включение новых карточек, конкурентные решения и атомарность
  образуют одну матрицу сохранности; ориентир 300 строк может быть превышен.
- Охват: новый изолированный модуль пробника, общий CLI/драйвер, тесты и
  документация. Продуктовые входы/права/UI, пространство в корзине, очистка,
  история, полный порядок и множество тегов не входят в срез.
- Модель: регистры состояния колонки и карточек; обычная правка/создание
  карточки атомарно подтверждает активность родителя. Каждое обычное удаление
  получает причинный ID группы; ранее удалённые карточки не переоформляются.
  Явное подтверждение удаления включает новые карточки в текущую группу;
  восстановление затрагивает только её членов. Часы не выбирают победителя.
- Фикстура: активное пространство, две колонки, активные и ранее удалённая
  карточки, ограниченные поля/положение/одно назначение. Не продуктовый формат.
- Проверки: Windows `bun run check`; Android `bun run check:automerge --android`
  (API 33/x86_64, arm64 CLI build); отдельные процессы, SQLite reload,
  повторы/перестановки, старые/конкурирующие решения, AFTER UPDATE ABORT.
- Обратимость и отказ: корзина/восстановление/повторное удаление сохраняют ID
  и данные; восстановление карточки в другую активную колонку не восстанавливает
  исходную колонку. Устаревший выбор и сбой не сохраняют частичное действие.

# ADR-0026: транспорт по результатам прототипов P01

Дата: 2026-10-30.

Статус: технический выбор для дальнейшего проектирования; пригодность
ограниченного среза подтверждена EV-016–EV-023. Полная приёмка P01/A62 открыта.

## Решение и основания

Продолжать с выбранной Tauri 2; Kotlin остаётся платформенной интеграцией,
резерв Kotlin + WebView из ADR-0001 не активируется. Сборки двух ABI,
реальный WebView/IPC, SQLite, доска/Markdown/QR, физическая камера и внешний
HTTP проверены в интегрированных прототипах. BUG-001 и BUG-002 исправлены
и перепроверены; открытого дефекта, требующего смены оболочки, нет.

Для локального интерфейса Android использовать Tauri IPC к общим операциям
Rust, не запускать loopback HTTP ради собственного UI. Для Windows сохранить
браузерный HTTP, для внешнего доступа к открытому Android — Axum через
настроенный Tailscale. Основание — равенство результатов, валидации,
сохранённого состояния и отказов через оба адаптера, а не сравнение их скорости.
Новый транспорт, собственный мост Kotlin или автоматический HTTP fallback
не нужны для проверенного среза. Отказ адаптера остаётся явным отказом.

SQLite bundled сохраняется как локальная основа, общий Storage — единственный
владелец авторитетных данных. Rust остаётся источником контракта, OpenAPI/TS —
производные. Bun выполняет генерацию/Vite/драйверы; для vue-tsc нужен
закреплённый Node LTS (EV-015). Версии не обновляются в итоговой проверке:
источники — `scripts/environment-versions.json`, Cargo.lock и bun.lock.

## Границы и дальнейшие проверки

Синтетический HTTP-сервер P01.10 по умолчанию выключен и управляется локально;
Home/сон/уничтожение Activity отзывают сессию. Восстановление listener после
VPN restart действует только внутри ещё разрешённой сессии. Не обещается
работа при закрытом APK. Сохраняются [границы ADR-0025](0025-limited-prototype-http.md).

Прототипные ключи, синтетические полномочия A/B, snapshot-as-expected и
тестовое хранилище нельзя переносить в продукт как готовую архитектуру доступа.
DEC-001 остаётся открытым для границ пакетов/адаптеров P03; DEC-003 — для
продуктовых полномочий. Это уточнение внутреннего транспорта не меняет
пользовательский договор, процесс подключения или правила синхронизации.

Методика [EV-024](../../agent/verification/EV-024-prototype-review.md)
относится к доступным операциям. Эмулятор/debug не подтверждает release/Galaxy A32,
полный IME/редактор и A62 ещё требуют проверки. Automerge и согласованная
фиксация с SQLite проверяются в P02 до продуктовой модели P03.

Если обнаружится ограничение IPC/оболочки, блокирующее обязательное поведение,
воспроизвести его на общем сценарии и оформить отдельное решение о транспорте
или резерве. Удаление этого технического выбора не меняет формат синтетических
данных: текущие адаптеры вызывают те же операции общего ядра.

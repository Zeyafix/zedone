# Защищённый канал: граница доступного

P06.01 связывает защищённый канал, OS-store, общий host API и формы ручного
подключения. Используйте [host offer/session и UI](pending-device-request.md),
не посылайте код через plaintext HTTP. Явный listener доступен через CLI --listen
или настройки; синхронизация пространств остаётся отдельным шагом.
invitation.* выполняются через общий Service с прежними административными правами.

TLS требует заранее доверенного SHA-256 отпечатка сертификата другой стороны.
Его нельзя брать из ответа непроверенного сервера, автоматически менять при
ошибке или заменять проверкой произвольного сертификата системного CA.
Составной ручной код P06.01.2.3 передаёт отпечаток вместе с приглашением;
QR остаётся следующим шагом. Несовпадение останавливает подключение до передачи секрета.

Идентичность канала сохраняется отдельно от команд, receipts, локальных
данных пространства и резервных копий пространств. Чтение/удаление секретов
из renderer недоступно. Утрата/повреждение хранилища требует явного решения;
создавать новую идентичность вместо ошибки запрещено. Явные удаление и новое
создание меняют отпечаток и требуют нового доверенного подключения.

Человек и агент используют один Service/host API процесса подключения;
прямое изменение SQLite или обход проверок прав запрещены.
Решение и ограничения: [ADR-0055](../architecture/decisions/0055-protected-device-channel.md).

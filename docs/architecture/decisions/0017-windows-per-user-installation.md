# ADR-0017: Inno Setup для установки ZeDone текущему пользователю Windows

Дата: 2026-10-27.

Статус: принято разработчиком, включая выбор Inno Setup. Версия инструмента ещё определяется; реализация и техническая проверка не выполнены.

## Контекст

Для Windows уже выбраны установщик с GitHub, ручной запуск ярлыком, локальный сервер с браузерным интерфейсом и ручная установка обновлений с сохранением данных. Требовалось выбрать область установки и потребность в повышенных правах.

Разработчик выбрал установку только для текущей учётной записи без запроса прав администратора. Установка сразу для всех пользователей ПК рассмотрена как альтернатива и не входит в первую версию.

Затем разработчик выбрал Inno Setup для создания установщика. Официальная документация описывает EXE-установщик, режим без повышения прав, ярлыки и средство удаления. Это основание выбора возможностей, а не подтверждение пригодности готовой сборки ZeDone.

## Решение

- Средство создания Windows-установщика — Inno Setup. Оно используется при сборке, результат поставки — EXE-установщик с ярлыками и средством удаления.
- Установка ZeDone на Windows выполняется только для текущей учётной записи без запроса прав администратора.
- Ручная установка обновлений сохраняет тот же режим текущего пользователя без запроса прав администратора.
- Файлы программы, ярлыки и регистрация установки размещаются в доступной текущему пользователю области. Точные пути определяются при реализации.
- Сохраняются отдельное от файлов программы хранение данных, ручной запуск, браузерный интерфейс и управление локальным процессом через трей и CLI. Автозапуск ОС в первую версию не добавляется.
- Удаление программы является обратной операцией установки. Отдельные независимые выборы очистки рабочих данных и автоматических копий, включая разрешённую окончательную локальную очистку после предупреждения/подтверждения как исключение из обратимости, определены в [ADR-0021](0021-uninstall-data-cleanup.md).

## Открытые технические вопросы

Версия Inno Setup, сценарий и параметры сборки, безопасная замена работающего приложения, проверка обновлений и оформление выпуска ещё определяются и проверяются в DEC-008/P08. Для режима без повышения прав у Inno Setup предусмотрен `PrivilegesRequired=lowest`; корректность полного сценария ZeDone, включая зависимости и обновление, проверяется из обычной учётной записи.

Для Android сохраняется поставка APK. Паритет прикладных операций не требует одинакового механизма установки ОС.

## Проверка и правила проекта

Уточнены сценарий 37 и A37/P08: сборка EXE-установщика через Inno Setup, установка из обычной учётной записи без административных прав, отсутствие запроса повышения, запуск ярлыком, ручная установка обновления в том же режиме с сохранением данных и страховочной копией перед необходимой миграцией, доступность средства удаления. Выборы очистки данных проверяются отдельно в сценарии 63/A63; принятое исключение из обратимости и открытая техническая реализация описаны в ADR-0021. Критерии остаются `not_run`.

Документация отражает выбор. Удаление программы, общий API прикладных операций, паритет Windows/Android и единое авторитетное локальное состояние сохраняются как требования. Реализация и продуктовая приёмка отсутствуют.

## Локальная проверка

- Группа включает все три ID, включая переименованный тег. Неполные, пустые,
  повторные/одинаковые Unicode-ключи, занятые и stale варианты не меняют данные.
  `Все`/`Всё` допустимы как разные имена.
- Полный выбор сохраняет ID, связи и поля карточки. После решения доступны
  обычные переименования/назначения/снятия, replay не отменяет позднюю правку.
- Одинаковые и разные независимые решения, последующее локальное переименование
  перед доставкой чужого решения, перестановки/повторы и restart сохраняют
  варианты. Даже один спорный результат блокирует всю историческую группу.
- Права ReadWrite и отзыв проверяются также перед replay. Все контрольные
  границы SQL commit покрыты общим тестом с S05: частичного набора имён нет.
- Windows/native Android матрицы passed; desktop/touch UI проверил полный ввод,
  отмену, stale с сохранением введённых имён, новое явное подтверждение и
  закрытие формы при смене пространства. Фоновые действия доски заблокированы
  до закрытия формы. Форма не вычисляет собственную идентичность/Unicode-ключи.

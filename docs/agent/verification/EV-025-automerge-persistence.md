Один документ на синтетическое пространство; два фиксированных участника A/B.
Automerge сосредоточен во внутреннем модуле общего Rust-ядра. Это проверочный
CLI, без нового UI, HTTP/IPC-входа или доступа к продуктовой базе. Состояние
документа, локальная идентичность участника и долговечное состояние обмена
фиксируются одной транзакцией SQLite в отдельном каталоге.

Закреплён Automerge 0.12.0 после проверки официальной документации и
метаданных. `State::encode()` сохраняет долговечные сведения между сессиями;
временные флаги текущего соединения не выдаются за сохранённые. Перезапуск
начинает новую сессию обмена и должен доставить неотправленную правку.

Модель конфликтов, контейнеров, тегов, удаления против правок и измерения роста
остаются P02.02–P02.06; продуктовый контракт и права — P03. T05/S10 до полного
охвата P02 не получают passed. Пользовательские сценарии приложения не меняются.

При отказе триггера SQLite после UPDATE прежняя строка документа/actor/peer
сохраняется целиком, в том числе после повторного открытия базы; после снятия
отказа обмен продолжается. Ошибки чтения повреждённых байтов не пересоздают A
и не затрагивают B. При удерживаемой эксклюзивной блокировке запись отвергается.
Проверены возврат прежнего заголовка с сохранением истории и удаление/возврат
реплики A из снимка без изменения B.

Драйвер создаёт только собственные временные каталоги и очищает их; на Android
он требует явный `emulator-NNNN`, дополнительно проверяет признак эмулятора и
отвергает физический телефон. Подготовленная локальная AVD запущена без записи
снимков и в режиме read-only. Сведения среды и сырые логи остаются в игнорируемой
`docs/reports/p02-01/`.

## Ограничения и правила проекта

- Обратимость: возврат заголовка, удаление/возврат синтетической реплики проверены.
- Человек и агент используют один CLI и один модуль Rust; прямое редактирование
  базы нужно только отрицательным Rust-тестам, не является прикладным API.
- Документация: [команды и временная модель](../../development/automerge-prototype.md),
  ADR-0002, журнал и очередь отражают срез; продуктовый пользовательский договор прежний.
- Паритет проверен для нативного пробника Windows/Android x86_64. arm64 — только
  сборка; новый путь в APK/WebView и физический телефон не проверялись.
- SQLite — авторитетное локальное состояние. Документ, actor и sync state в одной
  строке/транзакции; JSON содержит только контрольные ожидания.

Полный файл документа сохраняется без сокращения истории. Эксперимент не
подтверждает итоговый формат продукта, одновременную запись нескольких процессов,
полномочия, все сценарии обрывов, kill/power-loss в середине commit, конфликты,
безопасность продуктового восстановления, производительность и бюджет памяти.
T05/S10 получают только partial по начальному срезу; DEC-002 остаётся open.

Объём больше ориентира 300 строк: атомарное хранение, обратное действие,
негативные проверки и один и тот же сценарий перезапуска двух платформ образуют
одну проверку. Независимые продуктовые изменения и модели P02.02–P02.06 не добавлены;
lock-файл сгенерирован Cargo, прежние версии зависимостей не обновлялись.

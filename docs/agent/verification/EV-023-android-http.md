Один проверяемый срез: HTTP в APK и IPC используют один экземпляр Storage;
временный доступ ограничен синтетическим пространством A, отзывается явно
и при приостановке Activity. Управление остаётся локальным. Продуктовые
права, подключение устройств, обмен и итоговый выбор транспорта не входят.

Объём превышает ориентир 300 строк: проверка одного внешнего входа в APK
требует вместе реализовать общий адаптер, ограничение доступа, отзыв,
жизненный цикл и сквозные проверки. Отрыв ограничений от сетевого входа
оставил бы промежуточный небезопасный срез. Генерируемые модели проверяются
отдельно от ручных изменений.

Сведения о конкретной машине и сырые логи остаются в `docs/reports/p01-10/`.
Изменения подготовлены к локальному коммиту по поручению разработчика; PR и новых Actions нет. Ветка и непроверенный сетевой охват сохраняются.

## Локальные результаты

| Проверка | Результат |
| --- | --- |
| `bun run check` | Пройдено: fmt, Clippy без предупреждений, 19 Rust-тестов, release, согласованность Rust/OpenAPI/TS, strict/vue-tsc, Vite, HTTP/Chromium и прежние сценарии |
| `bun run check:http` с Chrome и Opera | Оба пройдены: тот же ограниченный HTTP, браузерный стенд, данные/отказы/обратные операции |
| `bun run android:build` | x86_64 APK и instrumentation собраны на Windows |
| `bun run android:build aarch64` | arm64 APK и instrumentation собраны на Windows; исполнения arm64 в этом шаге нет |
| `bun run check:android` | Пройдено на AOSP Android 13/API 33 x86_64 без GMS, WebView 101: настоящий Axum внутри APK через временный adb-forward, общее хранилище с IPC, форма/права/жизненный цикл и прежние сценарии |
| Прямой HTTP через Tailscale | **Не выполнено**; разработчик подтвердил недоступность настройки сети и поручил продолжить локальные проверки. GAP-003, T04/A26 partial |

Проверены пустой/неверный ключ (401), точный Unicode echo, неверное тело (422),
Origin (403), начальное чтение даже без параметра access, запрещённые
seed/delete/restore/move_card/move_column при read для A/B, read/snapshot B,
запрет B также при write, отсутствие удалённого управления (404).
HTTP и локальный API дают одинаковые read/snapshot; разрешённое HTTP-перемещение
видно в IPC, устаревший expected отклоняется, удаление/восстановление A
сохраняют B. Реальный SQLITE_BUSY возвращается по HTTP APK как 503;
параллельные IPC/UI остаются отзывчивыми, после освобождения блокировки
данные неизменны и доступны явному чтению.

Rust проверяет отзыв уже открытого TCP-соединения и безопасный повторный запуск
на прежнем фиксированном порту после остановки. Каждый новый запуск создаёт
новый ключ. Ошибки bind/неразрешённого адреса не включают доступ, ошибочный
повтор start не повышает права текущей сессии.

В Android проверены настоящие сенсорные действия формы: начальное чтение,
отказ адреса и повтор, явное включение write и остановка. Home и сон экрана
отзывают доступ нативно; возврат не создаёт сессию. Отдельный
ActivityScenario.recreate проверяет отзыв и успешный новый явный запуск
с новым ключом. Реальный force-stop/запуск сохраняет SQLite, удаляет сессию;
старый ключ получает 401 на том же порту нового процесса.

Первые неуспешные запуски выявили ошибки драйвера: WebView ещё не готов,
два владельца последнего окна Tauri запускались в одном instrumentation-процессе.
Добавлены ожидание WebView и отдельные процессы для двух сценариев.
Это не засчитывалось как успешная проверка; повторный полный прогон пройден.
Одна ручная команда Gradle была вызвана вне каталога проекта и отклонена;
исправлен параметр каталога. Приложение ради этих ошибок драйвера не менялось.

## Границы и передача

Локальная проверка не доказывает маршрутизацию Tailscale, фактический bind
его адреса на Android, сетевые политики, работу на физическом телефоне,
обрыв/возврат настоящего туннеля или производительность. Нет CI/Linux
для нового среза; workflows выполнят расширенные общие/Android-сценарии
после отдельной публикации. T04/A26 остаются partial, P01.10 blocked;
готовность P01.11 и всего приложения не заявляется.

Пять правил проекта подтверждены в локальном синтетическом охвате:
остановка/повтор, смена ключа, обратные данные; общий API человека/агента;
документация пользователя/агента/разработчика и ADR-0025; HTTP на Windows
и Android-эмуляторе; единые Rust-модели и Storage APK. Реальный сетевой
паритет и продуктовые права не приняты. Тестовые сессии/forward/процессы
закрыты, A/B удалены через API; личный телефон не подключался и не менялся.

Продолжение: настроенный tailnet и Android → прямой запрос с ПК без adb-forward,
сопоставление IPC и матрица разрешений/отзыва/жизненного цикла/обрывов сети.
Инструкции: [разработчик](../../development/android-http-prototype.md),
[пользователь](../../user/prototype-http.md), [агент](../prototype-http.md).

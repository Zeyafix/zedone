# Графит

Тихая рабочая поверхность с характером тёмной бумаги: перекрёстные карандашные штрихи, серебряный текст и приглушённый медно-розовый акцент. Карточки выглядят как листы плотной бумаги, а не светящиеся панели. Это самостоятельный визуальный прототип приложения ZeDone.

## План и токены

| Токен | Цвет | Роль |
| --- | --- | --- |
| canvas | `#292C2E` | Графитовая основа и фактура |
| rail | `#232628` | Спокойная навигация по пространствам |
| paper | `#34383A` | Поверхность карточки |
| silver | `#E4E2DE` | Основной текст |
| muted | `#ACAFAD` | Описания, счётчики, вторичный текст |
| copper | `#C5A19A` | Добавление, текущая колонка, фокус |

Шрифты: системный Segoe UI Variable Text / Segoe UI / Arial для интерфейса; Georgia / Times New Roman для имени пространства и заголовка открытой карточки. Serif-акцент относится к личным мыслям и заметкам; рабочие карточки сохраняют быстрый, привычный рисунок текста. Внешних шрифтов нет.

Выравнивание левое. Доска — главный экран, без вступления и декоративных показателей. На ПК навигация занимает 214 px; содержимое использует оставшуюся ширину. Колонки разделяются воздухом и верхней кромкой, без лишнего набора вложенных панелей.

## Проверка замысла

Первый риск тёмного варианта — обычная чёрная панель с цветным акцентом. Поэтому основа заметно светлее чёрного, фон имеет тонкую тканую штриховку, а акцент близок по насыщенности к материалу. Убраны отдельные оболочки колонок, лишние подписи и значки действий на каждой карточке. Единственное выразительное решение — материальность поверхности; остальная композиция сдержанная.

Самооценка: выразительная, спокойная тёмная альтернатива; сильнее всего работает на просторной доске ПК. На мобильном больше места отдано чтению карточек, а фактура остаётся фоном. Системные шрифты делают вариант автономным, но точный рисунок текста зависит от ОС. Контраст мелких описаний требует проверки на реальном экране при дальнейшем переносе в приложение.

## Действия и доступность

- Поиск по заголовкам, описаниям и тегам; очистка кнопкой и Escape; `/` переводит фокус в поиск.
- Открытие карточки, редактирование всех полей, сохранение и отмена. Через выбор колонки карточку можно переместить и вернуть обратно.
- Добавление карточки в выбранную колонку; удаление из открытой карточки. Удаления складываются в стек и восстанавливаются в обратном порядке кнопкой «Восстановить», пока открыта страница.
- Переключение пространств. Исходные семь карточек принадлежат пространству «Моя неделя»; остальные два пространства начинают пустыми и поддерживают те же действия.
- На Android колонки переключаются вкладками. Навигация по пространствам открывается в диалоге. Действия и состояние общие с ПК.
- Нативные кнопки и поля, подписи, видимый фокус, модальные диалоги с Escape, клавиши стрелок / Home / End для вкладок, возврат фокуса, сообщения об изменениях для скринридера. Анимация открытия отключается при reduced motion.

## Запуск и ограничения

Открыть `index.html` через `file://`. Единственный внешний файл — относительный `../shared/demo-data.js`; он клонируется при запуске. Сеть, сервер, fetch, модули и зависимости не используются. Состояние хранится только в памяти страницы; перезагрузка возвращает исходные данные. Это демо визуального интерфейса, без реального сохранения, синхронизации и подключения к API ZeDone.

Проверено: синтаксис inline JS и `git diff --check`; html_preview на ширинах 1280, 390 и 360 px, а также форма редактирования на 390 px. В html_preview выполнен цикл поиска, очистки, открытия, отмены, сохранения, добавления, удаления и восстановления. Для снимков только в переданном preview-документе `100dvh` заменён на фиксированную высоту; исходный HTML использует размер окна. Родительская задача дополнительно проверила этот же цикл и перезагрузку через Playwright с `file://` на 1280 и 390 px. Это проверка адаптации HTML; нативный запуск Android в Device в рамках варианта не выполнялся.

Файлы варианта: `index.html`, `README.md`. Общие fixture, каталог, документация проекта и журнал не изменены. Обратные действия, общее состояние ПК и мобильной версии, семантическое управление человеком и агентом соблюдены в пределах демо. Интеграция с единым API продукта остаётся за пределами визуального прототипа.

В [разделе 4 Quick Start](../../development/quick-start-windows.md#4-подготовьте-средства-выпуска-и-связи-p0004) закреплены источники и база новых установок: Inno Setup 7.1.0 x64, Tailscale 1.104.2 Stable и GitHub CLI 2.103.3. Для существующих установок сначала проверяется фактическая версия; автоматическое обновление не требуется. Наличие закреплённых Tailscale/GitHub CLI проверено также в каталоге WinGet. Установка этих двух пакетов на чистой машине в данный результат не входит.

Команды Inno Setup проверяют SHA256 и Authenticode до установки, выбирают текущего пользователя и сохраняют журнал вне временной папки. Документированный блок компиляции выполнен на синтетическом `.iss`; результат создан только в игнорируемой временной папке и не запускался. Отдельная проверка некорректного `.iss` подтвердила отказ компилятора. Установщик ZeDone, его установка/обновление/удаление относятся к P08.02.

Для Tailscale описаны версия, служба, `status --json` и `netcheck`, трактовка неподключённого состояния и граница между диагностикой сети и связью двух устройств. Приведён источник Android APK без зависимости от Google Play. Настройка tailnet/входа, VPN-разрешение и проверка двух устройств относятся к P01.11/P06. Диагностический вывод с адресами остаётся локальным.

GitHub проверяется читающими командами: авторизация, метаданные/права репозитория, политика Actions, workflows/runs и Releases. Разделены публичное чтение, подтверждённые метаданные прав и ещё не выполненные операции записи. Отказ чтения административной политики не приравнивается автоматически к невозможности CI; публикация не используется для проверки доступа. Отложенные keystore/сертификаты подписи, SignTool, разрешения и секреты CI связаны с P01/P08 до их применения. Новые секреты не создавались и не читались.

Проверки документации и синтаксиса пройдены; требования и состояния всех 98 критериев сохранены. Машинные результаты установки/диагностики, ограничения и точная локальная приёмка T15 хранятся только в `docs/reports/`. Эта запись не меняет общий T15 и строки подготовки других машин. T17 остаётся `partial`: CI и полное воспроизведение ещё предстоят. Обратные действия описаны; человек и агент используют одни команды, единственная локальная точка продолжения — `state.json`. Продуктовые данные, API и требования паритета Windows/Android не изменены. Подготовка публикации — LOG-082; фактические SHA, PR и результат слияния проверяются по Git/GitHub. Машинные доказательства не публикуются; метаданные коммита используют публичное имя GitHub и адрес noreply.

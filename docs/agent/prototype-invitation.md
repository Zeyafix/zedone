# Синтетический ввод приглашения для агента

P01.09 добавляет stateless `POST /prototype/invitation` на loopback HTTP
прототипа и IPC `invitation` в APK. Камера не нужна; человек использует тот же
Rust-контракт из формы. HTTP внутри APK и удалённый доступ ещё не реализованы.

Для ручного ввода передайте
`{"source":"manual","address":"http://192.0.2.1:4317","code":"SYNTHETIC-ONLY"}`.
Для инспекции прочитанного текста передайте `{"source":"qr","text":"…"}`,
где text — JSON с двумя строками address/code. Точные схемы находятся в
`prototypes/openapi.json`, а не в отдельной ручной модели агента.

Ответ — неизменённые поля address/code. Пустые и пробельные поля, неверные типы,
неизвестные поля отклоняются. Адрес не открывается, данные не хранятся,
подключение, выдача прав и синхронизация не выполняются. Повтор безопасен,
поскольку операция ничего не изменяет; очистка UI удаляет только текущую форму.

Не объявляйте успех инспекции доказательством подключения или годности кода.
Нет результата камеры — состояние сканера, а не отказ общего приглашения.

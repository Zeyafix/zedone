# ADR-0004: Reka UI и стандартные HTML-элементы

Дата: 2026-10-26.

Статус: принято разработчиком. Техническая проверка в ZeDone ещё не выполнена.

## Контекст

ZeDone использует общий интерфейс Vue + TypeScript + Vite с собственным дизайном на Windows и Android. Разработкой занимается AI-агент; готовое поведение сложных компонентов уменьшает объём собственного кода для клавиатурной навигации, фокуса и доступности. Снижение частоты ошибок агента пока не измерено.

Разработчик согласовал использование Reka UI для сложных компонентов, стандартных HTML-элементов для простых кнопок и полей и собственного оформления ZeDone.

## Решение

- Для сложных взаимодействий, например диалоговых окон, выпадающих меню и вкладок, использовать Reka UI.
- Для простых кнопок и полей использовать стандартные семантические HTML-элементы.
- Подключать только компоненты, которые нужны ZeDone. Конкретный набор и совместимая версия определяются при реализации; выбор библиотеки не требует добавлять все её компоненты.
- Собственное оформление ZeDone задаётся общим компонентам приложения и используется на обеих платформах. Готовое поведение Reka UI не заменяет оформление и прикладные правила ядра.
- Действия компонентов вызывают те же прикладные операции Rust-ядра, что HTTP и CLI. Данные интерфейса остаются производным представлением авторитетного локального состояния.

## Проверка и границы

В P01 на небольшом срезе проверить установку и сборку с Bun/Vue/TypeScript/Vite/Tauri, нужные диалог или меню, фокус, клавиатурное и сенсорное управление, экранную клавиатуру и системную кнопку «Назад» Android. Полный охват в P05 включает собственное оформление, обе темы, читаемость, доступные названия элементов, поведение закрытия и сохранность ввода по согласованным правилам. Проверки проводятся в целевых браузерах Windows и Android APK.

Выбор библиотеки до технической проверки принят как ограничение. Наличие встроенных механизмов доступности не подтверждает корректность интеграции ZeDone; T02 и T08 остаются not_run. Библиотеки перетаскивания и Markdown этим решением не выбираются.

Требования обратимости, общего API человека и агента, паритета Windows/Android и единого источника данных сохраняются. Изменений реализации пока нет.

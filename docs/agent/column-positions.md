# Разрешение позиции колонки

Вызовите `column.inspect_positions` с `space` и `column` при праве чтения
пространства. Ответ содержит `column` и `choices`: сохранённая `position`
(Rank) и `before` — ближайшая однозначно расположенная колонка после этой
позиции либо null. Подпись вычисляет ядро, клиент не рассчитывает ранги.

Для выбора отправьте `column.resolve_position` с теми же `space`/`column`,
точной выбранной `position` и `expected=column.version`. Нужен ReadWrite.
Обычный envelope `id`/`operation`, HTTP `/v1/commands/column.resolve_position`,
CLI `--operation column.resolve_position` и IPC используют один Service.

Несохранённая позиция — `invalid_request`; отсутствие нескольких вариантов
либо удаление колонки — `conflict`. Пространство в корзине/с конфликтом
удаления не восстанавливается. Собственный конфликт имени сохраняется,
карточки и их версии/история выбором не меняются. Работа с карточками активной
колонки без собственных конфликтов продолжается при споре её позиции.

Правки содержимого входят в версию колонки. При `stale_state` перечитайте
варианты и подготовьте новое явное решение. При неизвестном исходе повторяйте
исходные ID/параметры/expected; отзыв доступа блокирует replay. Разные независимые
решения снова конфликтуют, одинаковые сходятся. Обычная `column.move` после
разрешения собственных конфликтов позволяет вернуть прежнее место.

Разные колонки между одними соседями автоматически сохраняются в устойчивом
порядке. В UI спорная колонка с карточками находится в области «Конфликты»
перед обычной доской; до выбора её нельзя использовать как обычного соседа.

При одновременном конфликте `card.placements` и `column.positions` решения
независимы и допустимы в любом порядке. `column.resolve_position` сохраняет
собственные варианты карточки и её блокировку. `card.resolve_placement` может
выбрать активную колонку со спорной позицией: после выбора обычные действия
карточки доступны при отсутствии других её конфликтов. Перечитывайте версию
колонки после изменения содержимого; решение карточки не разрешает колонку.

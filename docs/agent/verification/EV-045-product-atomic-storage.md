## Результат

`zedone-storage` реализует отдельный SQLite worker с ограниченной асинхронной
очередью. Поля и пользовательская история принадлежат одному Automerge-графу
пространства. Загрузка затрагивает только выбранные пространства, локальная
правка дописывает change; принятые входящие changes сохраняются даже без
зависимостей. Actor, графы, peer progress и JSON результата фиксируются одной
транзакцией. Непрозрачные ключ/запрос результата не становятся публичным форматом
команд. Архитектура, схема, цена и ограничения — [ADR-0028](../../architecture/decisions/0028-atomic-storage.md).

Ошибка изменяющего примитива запрещает commit всего контекста, даже если callback
её перехватил. Ошибка сериализации результата также откатывает изменения.
Успех возможен только после commit. Ошибка на границе commit, паника или потеря
ответа не объявляются достоверным отказом. Отмена ожидания принятого задания
не отменяет запись; доказательство результата остаётся на диске.

Начальная схема 1 создаётся только в пустой новой базе, вместе с идентичностью
приложения и версией. Новая/неизвестная версия, чужая база и неверный состав схемы
отклоняются без исправления/пересоздания; тесты сравнивают байты исходного файла.
Перехода между схемами и миграции пользовательской базы в этом объёме нет.

## Правила проекта и ограничения

- Обратимость: пользовательских действий ещё нет; синтетическая правка обращается
  новой правкой с сохранением прежней истории. Тестовые базы изолированы и удаляются.
  Прямое удаление причинного графа как «обратная операция» не добавлено.
- Человек и агент: один Rust-контракт и общий будущий путь core → storage;
  низкоуровневые callbacks не предоставляют альтернативного пользовательского входа.
  UI/HTTP/CLI/IPC и проверки прав остаются P03.03–05.
- Документация: обновлены архитектура/ADR, разработка, очередь и журнал.
  Нового пользовательского поведения нет, отдельная инструкция UI не требуется.
- Паритет: одинаковые нативные тесты Windows/Android x86_64, обе Android ABI собраны;
  APK/WebView, физический arm64 и полный продуктовый UX здесь не принимаются.
- Единый источник: одна SQLite устройства, changes являются графом, поля/история
  читаются из него; независимо изменяемой копии полей/поискового индекса нет.
  OpenAPI не менялся и по-прежнему генерируется из Rust.

Полный выбранный граф загружается для каждой транзакции; цена чтения растёт
с историей. Рост графа/результатов не ограничен, автоматического удаления нет.
Пользовательские правила истории, полный sync-протокол, права/пауза/повторы,
порты прикладных обработчиков, снимки/миграции и полный бюджет приложения впереди.
Остановка процесса не является доказательством физического отключения питания.

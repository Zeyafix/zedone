# Поиск карточек

Поиск доступен через общий API; экран поиска добавляется в P05.07.
Можно искать в одном пространстве или во всех доступных локальных пространствах.
Выполненные карточки включаются, однозначная корзина исключается.

Запрос ищется целиком в текущем заголовке либо описании: «план» находит
«перепланировка», «купить молоко» требует соседних слов в таком порядке.
Регистр не учитывается, Café/Café и Straße/STRASSE совпадают, «е»/«ё» различаются.
Внутренние пробелы, табуляция, переносы и специальные символы ищутся буквально.
Краевые пробельные символы запроса обрезаются. Пустой запрос показывает все
доступные карточки выбранной области, сохраняя саму область.

Учитываются все текущие конфликтующие тексты; карточка появляется один раз
с отметкой конфликта. История прежних правок не ищется. Результаты следуют
порядку доски; карточки со спорным местом/удалением идут первыми внутри
пространства. При поиске везде пространства со спорным названием идут первыми,
остальные — по именам.

Поиск сохраняет данные. Новый запрос показывает последующие изменения;
повтор доставки прежнего запроса возвращает прежний результат, если доступ
к каждому его пространству по-прежнему разрешён.

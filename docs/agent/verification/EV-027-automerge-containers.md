P02.03 разделён до реализации: конфликты названий и конфликты положения —
самостоятельные проверяемые результаты. Этот срез проверяет только первый:
один синтетический документ пространства с двумя одноимёнными колонками и
карточкой; связи заданы ID объектов, а не именами. Названия используют модель
неизменяемых присваиваний P02.02. Решение проверяет состояние выбранного объекта,
обычные правки блокируются только при его собственном конфликте, содержимое
остаётся доступным с учётом собственных конфликтов вложенных объектов.

Продуктовые создание/удаление, UI/HTTP/IPC, пользовательский порядок,
перемещения и сортировка списка пространств/поиска не входят в этот срез.
S03 получает только частичные доказательства; DEC-002 и T05 остаются открытыми.
Фиксированная синтетическая иерархия — подготовка проверки, а не пользовательская
операция создания без обратного удаления. Корзина/удаления остаются в P02.05.

## Ограничения и передача

Паритет проверен нативным CLI на Windows/Android x86_64. Физический arm64,
новый APK/WebView, продуктовые UI/HTTP/IPC/права, создание произвольных объектов,
генерация ID, удаления и рост/память не проверялись. Структура фиксированной
иерархии не обещает продуктовую схему или миграцию прежних временных баз.
Переставляются изменения `apply_changes`, а не сообщения одной sync-сессии,
для которой требуется надёжный упорядоченный поток.

S03 partial: проверены названия и доступность содержимого в модели, но группы,
сортировка списка пространств/поиска и продуктовые адаптеры ещё впереди.
P02.03.2 проверяет порядок/перемещения после интеграции P02.03.1. T05/DEC-002
не закрыты. P02.04 и последующие модели не добавлены.

Объём превышает ориентир 300 строк: один результат требует общей модели
присваиваний, иерархии и блокировок, единого сценария перезапусков двух платформ
и отрицательных проверок сохранности/актуальности. Независимый порядок заранее
вынесен в P02.03.2; дальнейшее разделение разорвало бы доказательства этого
поведения. Публикация — LOG-197; результат PR #21/CI/merge подтверждён
Git/GitHub при передаче CI.01 (LOG-201). Исходная база — d066991.

# Данные сборок разработки

До реализации всего плана ZeDone не поддерживает перенос данных между
разными версиями сборок разработки. Новая сборка может использовать изменённую
стартовую схему и отказаться открывать базу предыдущей сборки.

При таком отказе база сохраняется без изменений. Приложение не удаляет её и
не создаёт пустую базу поверх неё. Для проверки новой сборки используйте
отдельный пустой каталог данных; прежний каталог и резервные копии сохраните.

Повторный запуск той же сборки сохраняет данные, права, историю и результаты
команд. Поддержка прошлых версий вводится после реализации всего плана;
[ADR-0047](../architecture/decisions/0047-initial-schema-until-plan-complete.md).

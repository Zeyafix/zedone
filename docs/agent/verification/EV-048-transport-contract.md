## Реализовано

`CommandRequest<C>`/`decode_request<C>` проверяют имя конкретной операции,
ненулевой 16-байтовый ID, строгие параметры и исходные условия. JSON не выдаёт
полномочий. `CommandResponse<T>` различает подтверждённый исходный результат,
признак его повтора и машинную ошибку. Неизвестный исход не превращается в успех.
Сериализация ответа происходит после завершения транзакции, не внутри callback.
Субъект, учётные данные, права и часы не добавлены в конверт.

OpenAPI и TypeScript выведены из Rust. Тестовые операции не зарегистрированы,
`paths` пуст; Value-схемы конвертов не заменяют конкретную валидацию команд.
У ID/StateVersion в OpenAPI точные длины и диапазон целых байтов. У ответа
строгие независимые варианты. Договор/обоснование —
[ADR-0031](../../architecture/decisions/0031-shared-command-wire-contract.md).

Root package/lock закрепляют openapi-typescript 7.13.0 и TypeScript 5.9.3,
уже использованные в прототипах; root не зависит от prototype workspace.
Генерация/сверка/типизация включены в product-check и существующие CI jobs;
добавлены установка frozen lock и фильтры новых входных файлов. GitHub CI
этого изменения ещё не запускался. Схема SQLite 1 и хранимые receipts,
Rust-зависимости и прототипы не менялись.

## Пять правил и ограничения

- Обратимость: проверен JSON-повтор после обратного действия и restart без
  отмены позднего состояния. Продуктовые действия остаются P04.
- Человек/агент: один договор ядра; нет публичного обхода через тестовый handler
  или свободный Value. Настоящего HTTP/CLI/IPC/UI ещё нет.
- Документация: актуальны ADR, архитектура, инструкции разработчика/агента,
  очередь/журнал. Пользовательское поведение не добавлено.
- Паритет: одинаковые 61 тест Windows/нативного Android x86_64 и обе ABI
  release/unsafe passed. APK/UI/физический arm64/локальный Linux не проверены.
- Источник истины: Rust → OpenAPI → TS; данных/прав/receipt отдельно не копируем.
  Схема SQLite 1 и авторитетное состояние не меняются.

Генератор ограничивает разворачивание больших tuple: StateVersion в TS —
`number[]`. TS также не проверяет диапазон байта/ненулевой ID. Runtime Rust
обязателен; OpenAPI содержит полные ограничения длины/элементов.
Клиентская генерация ID, число попыток/паузы/таймауты, права/часы/bootstrap и
адаптеры ещё не реализованы. Защита утраты/отката базы обязательна до P07.
T06/A08/A26 и DEC-003 не закрываются; новых зарегистрированных багов нет.

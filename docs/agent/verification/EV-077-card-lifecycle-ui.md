## Реализация и границы

`workspace-api.ts` расширяет типизированные чтения/мутации прежнего контракта.
`SpacesView.vue` читает список карточек одним запросом на пространство,
группирует его за один проход и проверяет поколения ответов. `CardsList.vue`
отображает порядок API, без второй изменяемой модели. Карточки с неоднозначной
колонкой либо вне активных колонок видны отдельно, один раз, только для чтения.
Корзина карточек отделена от корзины колонок. Групповые действия и восстановление
в другую колонку остаются P05.08; конфликтующие варианты доступны для просмотра,
разрешение — P06.

Исходные ID/subject/JSON/expected сохраняются прежним CommandClient до доставки;
ключ берётся из хоста, в очередь не попадает. Отказ не подменяет исходное
намерение; его удаление требует предупреждения/явного подтверждения. Успех
всегда перечитывает текущее состояние. Описание — Vue-интерполяция, без v-html
и внешних запросов; это ещё не продуктовая CommonMark-приёмка P05.04.

Пять правил в этом срезе соблюдены: создание обратно корзине/восстановлению;
человек и агент используют общий Service/API; user/agent/development docs
обновлены при прежней архитектуре; Windows/Android UI проверены; авторитетные
данные остаются в одной SQLite/Automerge/Rust-derived модели, localStorage
содержит только оформление и намерения доставки.

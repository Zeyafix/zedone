## Реализация

Один Vue UI предоставляет список пространств, открытие доски через fragment URL,
создание/переименование/корзину/восстановление обоих контейнеров и просмотр корзины
текущего уровня. Порядок/конфликтующие варианты — проекция общего API.
Обычные действия при конфликтах и операции с неподдерживаемым содержимым
блокируются с пояснением; авторитетное решение сохраняется за ядром.

Форма существующего объекта фиксирует версию свежего чтения. Stale не обновляет
старое намерение и не вызывает автоматического изменения. До доставки сохраняются
исходные ID/параметры через прежний CommandClient; после потери ответа/перезапуска
доступна явная проверка той же команды. Успех перечитывает текущее состояние,
не устанавливает старый snapshot receipt. Новые изменения блокируются при
непроверенном результате или недоступном хранилище намерений. Удаление записи
проверки имеет отдельное подтверждение и не обещает отмену принятой команды.
Ввод при отказе остаётся в форме. Ключ берётся из хоста перед каждой доставкой,
не входит в очередь. Rust/API/SQL/зависимости не менялись.

## Пять правил

- Обратимость: переименование в обе стороны, корзина и восстановление доступны
  через UI и общий API; удаление записи очереди не выдаётся за отмену команды.
- Человек и агент: одни команды/Service/права/версии/receipts через HTTP/CLI/IPC;
  UI не пишет в SQLite и не выводит права из кнопок.
- Документация: user/agent/development, ADR-0042, EV, очередь и журнал обновлены.
- Паритет: жизненный цикл проверен в Windows-браузерах и Android Device;
  ограничения дополнительных тем/arm64/CI явно сохранены выше.
- Источник истины: SQLite/Automerge и Rust-контракт прежние; UI — текущая проекция,
  localStorage — предпочтение темы и исходные намерения доставки без ключа.

# ADR-0005: SortableJS через VueDraggablePlus

Дата: 2026-10-26.

Статус: принято разработчиком. Синтетическая доска локально проверяется в P01.06;
полная продуктовая проверка остаётся в P05/P06.

## Контекст

В ZeDone требуется перетаскивание карточек между колонками одного пространства, изменение порядка карточек и колонок на Windows и Android. Все перемещения также доступны через явные команды интерфейса и общий API. Разработкой занимается AI-агент; готовая механика переноса и интеграция с Vue уменьшают объём собственного связующего кода. Снижение частоты ошибок агента пока не измерено.

## Решение

- Для перетаскивания использовать SortableJS через VueDraggablePlus. SortableJS отвечает за механику переноса, VueDraggablePlus связывает её с Vue и TypeScript.
- Использовать библиотеку для переноса карточек между колонками одного пространства и изменения порядка карточек и колонок. Точные совместимые версии и настройки определяются при подготовке прототипа.
- Завершение жеста вызывает ту же прикладную операцию Rust-ядра, что явная команда интерфейса, HTTP и CLI. Права, допустимость перемещения, конфликты и сохранение данных проверяет ядро.
- Отображение переноса до ответа ядра не считается успешным сохранением. При ошибке показывается причина, а представление согласуется с авторитетным состоянием; библиотека не создаёт отдельное независимо изменяемое хранилище порядка.
- Явные команды перемещения сохраняются для клавиатуры и управления без перетаскивания. Согласованные блокировки конфликтующих объектов, идентичность карточек и правила синхронизации порядка сохраняются.

## Проверка и границы

В P01 проверить небольшой срез с выбранными SortableJS/VueDraggablePlus и Bun/Vue/TypeScript/Vite/Tauri. Проверить перенос между колонками, порядок карточек и колонок, работу мышью и на сенсорном экране, различение прокрутки и перетаскивания, автоматическую прокрутку и корректное состояние при отказе ядра или ошибке сохранения. Отдельно проверить одинаковый прикладной результат перетаскивания и явной команды.

Полный охват в P05 включает целевые Chrome и Opera на Windows 11 и APK на Android 13, клавиатурное управление явными командами и отсутствие потери или дублирования карточек. Проверки согласованных конфликтов и обмена дополняются в P06. Эмулятор не подтверждает производительность целевого Galaxy A32.

Выбор до технической проверки принят как ограничение. Поддержка сенсорного ввода библиотекой не подтверждает пригодность жестов ZeDone на Android; актуальные результаты T02/T08/A41 ведутся в плане-журнале. Библиотеки редактора и просмотра Markdown этим решением не выбираются.

Требования обратимости, общего API человека и агента, паритета Windows/Android и единого источника данных сохраняются.

## Проверка P01.06

[EV-019](../../agent/verification/EV-019-board-interactions.md) фиксирует
`vue-draggable-plus 0.6.1` со встроенным SortableJS 1.15.2. Ручки и задержка
касания отделяют перенос от прокрутки; AutoScroll прокручивает списки и доску.
Производные списки UI не становятся источником порядка. Общие Rust-команды
перемещения сравнивают исходный снимок в транзакции SQLite, сохраняют карточки
и связи с колонками. Обратное действие — та же команда с прежней позицией.
SQL-отказ и потеря ответа требуют чтения авторитетного состояния.

Полный снимок в условии актуальности и позиционные ID колонок допустимы только
для синтетического P01. Продуктовые предусловия/идемпотентные повторы, идентичность
колонок, конфликты и обмен проектируются в P02–P06. Воспроизводимая правка
TypeScript-декларации библиотеки не меняет runtime и не отключает strict;
[описание и условия удаления](../../development/board-prototype.md).

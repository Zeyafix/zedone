## Карточка P02.06.3

- База `4724117`, общая ветка `feat/p02-06-snapshots-compaction` по поручению
  разработчика. .1/.2 реализованы; 13 целевых тестов passed.
- Цель: измерить на Windows и нативном Android рост пространства и истории,
  повторные сохранения, загрузку/обмен и память; зафиксировать пригодность и ограничения.
- Требования: T05/S10, ADR-0002/0019/0020, DEC-002/DEC-009.
- Профиль до измерений: один документ на пространство; новые карточки 32/256/1024,
  дискретные версии 100/500/500; отдельная длинная история 32/2000;
  описания 100 строк и отдельный профиль 200 строк. Точный UTF-8-объём, число

  Дополнительно прежние модели причинных тегов и рангов. Это контрольные нагрузки,
  не продуктовые лимиты и не группировка автосохранений.
- Release CLI, отдельный процесс каждого профиля. Холодная загрузка ОС не
  заявляется: повторные загрузки в том же процессе, статистика min/median/max
  и исходные замеры. Память — пик одного Rust-процесса через Windows PeakWorkingSet64
  либо Android/Linux VmHWM; другие счётчики подписаны отдельно. UI/браузер/WebView
  отсутствуют, A61/общий бюджет приложения не закрываются.
- Для чётных выборок указана верхняя медиана (элемент `len/2` после сортировки).
- Проверки: измерительный smoke в общем CLI-драйвере, полные измерения обеих
  платформ отдельно; `bun run check`, нативные Android-тесты/процессы и arm64-сборка.
  Без новых инструментов/зависимостей и без изменения физических устройств.
- Обратимость: измерения только на синтетике в собственных временных каталогах;
  данные измерителя не являются авторитетным состоянием приложения.
- Результат: verified локально. Итог пригодности определяется измерениями, а не
  числом закрытых строк. Новых коммита/PR/CI нет.

## Вывод и ограничения

- Проверенные правила и сохранность допускают дальнейшую работу с выбранным
  Automerge. Ограниченная проверка завершена локально; полного продуктового
  заключения о масштабе, UX и верхних границах всего приложения нет. T05/S10
  остаются partial до интеграции доказательств; DEC-002 сохраняет продуктовую
  схему/интеграцию P03, DEC-009 — итоговые нагрузки/бюджеты/физическое устройство.
- Однопространственный граф делает полный сырой снимок изолированным. Для него
  проверены новое восстановление, совместимые/несовместимые независимые правки,
  сохранение нерешённых вариантов/истории/корзины и локальная постоянная пауза.
  Полная композиция прежних порядка/каталога тегов и продуктовый формат ещё
  не принимаются. Подробности — [модель](../../architecture/automerge-model.md).
- Переупаковка безопасно сокращает поток отдельных изменений, VACUUM освобождает
  пустые страницы. Обычный Store уже пишет компактный документ; в этих профилях
  повторная упаковка после восстановления не уменьшает BLOB.
- После очистки пользовательской истории число изменений графа увеличивается
  на одно, прежний checkpoint читается, компактный документ не возвращается
  к размеру пустой истории. Это проверенное сохранение причинных сведений,
  а не ограниченный рост или гарантированное стирание прежних байтов.
- Рост числа объектов увеличивает стоимость полного view на каждую правку;
  рост истории увеличивает загрузку, полный save и пиковую память.
  Пробник нельзя целиком переносить в продуктовый горячий путь. В P03 нужны
  проверенные границы загружаемых документов, производные представления из
  того же авторитетного состояния и выбор записи/загрузки по фактическим данным.
  При необходимости другой гранулярности документов устойчивые прикладные ID
  проектируются до продуктового формата, а не заменяются текущими Object ID.
- Когорты тегов проверены для 8/16/32 независимых одноимённых созданий
  (8/24/56 исходных ID суммарно): исторические чтения и обход групп становятся
  дороже. Ранги после 4096 вставок перед одним соседом имеют 133 компонента.
  Ни одна из этих моделей не объявляется неограниченно масштабируемой.
- Собственный модуль содержит около 10.7 тыс. строк Rust, включая сценарии и
  тесты; это объём прототипов, не размер будущего ядра. Критическая собственная
  логика — причинные группы/границы, каталог тегов, проекции и восстановление
  конфликтов; она требует сохранения этих регрессий при переносе. Снижение
  частоты ошибок AI-агента не измерено.
- Описания повторяющиеся и хорошо сжимаются. Проверены конечные нагрузки,
  повторные загрузки, отдельные снимок/обмен/восстановление; нет доказательства
  устойчивой памяти при неограниченном времени, экстремальных конфликтах,
  неограниченном росте границ очистки или произвольном содержимом. Метрики CLI
  не заменяют полный набор процессов браузера/WebView и физический arm64.

Сырые логи, условия машины, точные объёмы/времена и SHA-256 — в игнорируемых
`docs/reports/p02-06/measurements-host.json`, `measurements-android.json`,
`verification.json`. Машинные пути/инвентаризация не публикуются.

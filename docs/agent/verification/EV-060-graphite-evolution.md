## Реальные проверки

- Chromium/Playwright, `file://`, без сервера: семь вариантов на 1280 × 860 и
  360/390/412 × 844 — все 28 компоновок прошли без ошибок JavaScript,
  HTTP(S)-запросов и горизонтального переполнения документа. Снимки ПК/390 px
  каждого варианта просмотрены. На чёрно-золотом фоне визуально различимы точки
  и более редкие крупные плюсики; карточки непрозрачны и сохраняют читаемость.
- Все шесть новых файлов дополнительно скопированы отдельно от каталога и
  открыты через `file://`: исходная карточка доступна, ошибок загрузки и JS нет.
  Статическая проверка не обнаружила внешних ресурсов. Исходный «Графит» сохраняет
  прежний относительный `shared/demo-data.js`; его автономность одним файлом не заявляется.
- Финальные 14 сценарных прогонов (семь вариантов × ПК/390 px): поиск карточки
  в другой колонке, очистка, открытие, редактирование с отменой, сохранение,
  буквальный вывод пользовательского HTML, ширина редактора, добавление,
  удаление/восстановление, обратное редактирование и сброс перезагрузкой — passed.
  Управление выполнялось по доступным ролям и названиям. Для «Фокуса» проверялась
  встроенная панель вместо обязательного диалога, для вкладок выбиралась нужная колонка.
- Каталог: все семь кнопок выбирают правильные файлы в обеих рамках и отдельную
  ссылку. Три режима, три ширины телефона, прямой `#black-gold` и сброс работают.
  На 360, 390 и 800 px нет горизонтального переполнения. Отдельно на 1500 × 1600
  проверен сброс реальных изменений в чёрно-золотом макете в обеих рамках.
- Проверены локальные ссылки, whitespace и синтаксис девяти inline-скриптов в
  11 файлах каталога. Встроенные наборы всех шести новых макетов точно сопоставлены
  с `shared/demo-data.js`: пространство, пространства, колонки и семь карточек совпадают.
  Контрольная сумма оригинала совпадает. `git diff --check` прошёл.
- Копия каталога для чата встраивает семь документов без локальных ссылок на ресурсы.
  `html_preview` на 728 px: высота содержимого 2001 px, consoleMessages пусты
  в светлой и тёмной темах. Исходный каталог не заменяется этим представлением.

## Пять правил и ограничения

| Правило | Результат в охвате макетов |
| --- | --- |
| Обратимость | В каждом варианте проверены отмена редактирования, обратная правка, удаление/восстановление и сброс. Глубина undo зависит от реализации макета. |
| Человек и агент | Одни семантические кнопки и поля; проверки выполняют те же действия. Продуктовый API не подключён, его паритет не переопределяется. |
| Документация | Актуальны README каталога, планы в HTML, development-инструкция, EV и журнал. Продуктовое пользовательское поведение и архитектура не менялись. |
| ПК и Android | Проверены адаптивный HTML и одинаковые базовые действия на узком экране. Android Device/APK/WebView и производительность устройства не проверялись. |
| Источник истины | В каждом документе одно состояние для всех размеров. Все шесть встроенных исходных наборов точно равны общему fixture; между окнами синхронизации нет. |

P03.05/BUG-004, продуктовые критерии и очередь не меняются. Коммита/PR/CI нет.
